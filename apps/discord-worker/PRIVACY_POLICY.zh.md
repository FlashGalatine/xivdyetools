# XIV Dye Tools Discord 机器人 - 隐私政策

> 本文档是为方便用户提供的翻译版本。英文版为具有法律效力的正式文本；如两者存在差异，以英文版为准。[English](PRIVACY_POLICY.md)

**最后更新**：2026-09-16

## 1. 引言

本隐私政策说明 XIV Dye Tools Discord 机器人（“本机器人”、“我们”）在您使用我们的服务时如何收集、使用和
保护您的信息。

我们致力于保护您的隐私，并对我们的数据处理方式保持透明。本机器人是一个同人社区工具，与 Square Enix
没有从属关系。

## 2. 我们收集的数据

### 自动收集的信息

| 数据类型 | 用途 | 保留期限 |
|-----------|---------|-----------|
| Discord 用户 ID | 用于识别用户以处理偏好设置、预设收藏、投票、速率限制以及首次运行提示标记；也用作每日单用户活动标记的键，并在使用统计中被计数（但绝不列出）——见下文*使用分析* | 直至请求删除数据为止（使用统计记录：见*使用分析*） |
| Discord 用户名 | 为社区预设提交内容标注作者 | 直至请求删除数据为止 |
| 用户语言 | 提供本地化的机器人回复；Discord 客户端语言（归入本机器人支持的六种语言之一，或“其他”）也会记录在使用统计中——见下文*使用分析* | 已保存的偏好：直至被清除。使用统计分桶：见*使用分析* |
| 服务器 ID／频道 ID | 在上下文中处理命令 | 不存储。使用统计只记录命令是在服务器中还是在私信中运行（取值 `guild` / `dm`）——绝不记录该服务器或频道的 ID |

### 您提供的信息

| 数据类型 | 用途 | 保留期限 |
|-----------|---------|-----------|
| 偏好设置 | 语言、混合模式、匹配算法、结果数量、部族、性别、默认市场服务器 / 大区、是否默认显示市场布告板价格、颜色显示开关、主题，以及要从搜索结果中排除的染剂类别（金属、粉彩、暗色、宇宙、伊修加德、高价、商店、制作） | 直至您重置它们或请求删除 |
| 预设收藏 | 您用 `/preset favorite add` 标记的最多 50 个社区预设——该预设的 id 以及您保存时它的名称 | 直至您移除它们或请求删除 |
| 首次运行提示标记 | 一个逐用户的标记，记录 5.0 欢迎提示是否已向您展示；不携带任何内容 | 180 天后自动过期 |
| 预设提交 | 名称、描述、染剂、标签、类别 | 无限期保留（社区内容） |
| 投票 | 您对社区预设投的票 | 直至您撤销投票或请求删除 |

### 速率限制数据

- 按用户、按命令的计数器由 Cloudflare 的 Workers 速率限制服务持有，窗口为 60 秒，绝不会写入 KV。
- **回退方案**：在没有原生速率限制绑定的部署环境中，计数器会改为保存在 Cloudflare KV 中，键中包含您的
  Discord 用户 ID 与命令名称，有效期为 120 秒。生产环境与测试环境都绑定了原生服务，因此这条路径在那里
  不会被使用。
- 本机器人在速率限制时绝不会查看或使用您的 IP 地址——它通过 Discord 用户 ID 识别您，因为命令来自
  Discord 的服务器，而不是直接来自您本人。
- 不涉及任何第三方。

### 使用分析

为了保持机器人的健康运行并支持 `/stats` 面板，我们会为您运行的每一个命令或点击的每一个复制按钮记录：

| 数据 | 位置 | 保留期限 |
|------|-------|-----------|
| 命令名称与子命令、是否得到了回应，以及——如果出现问题——一个粗粒度的失败分类（速率限制、被预设或市场服务拒绝、市场数据不可用、预设服务不可用、上传的图像或 `.chara` 文件无法读取、渲染失败、未知；绝不包含错误消息本身）、耗时、是在服务器中还是在私信中运行（`guild` / `dm`——绝不记录服务器的 ID）、您的 Discord 客户端语言（本机器人支持的六种语言之一，或“其他”）、您按下的是哪个复制按钮（hex / RGB / HSV），以及您的 Discord 用户 ID（仅用于统计独立用户数） | Cloudflare Workers Analytics Engine | Cloudflare 的 Analytics Engine 保留期限（撰写本文时为 3 个月） |
| 汇总计数器——命令总数、各命令的计数、成功/失败次数（不含用户数据） | Cloudflare KV | 30 天（自动 TTL） |
| 每位用户每天一个键（`usertrack:{date}:{userId}`，值为 `1`），用于统计每日活跃用户 | Cloudflare KV | 30 天（自动 TTL） |

这些记录绝不包含消息内容、命令选项的值、服务器名称或频道 ID。Analytics Engine 中的数据一旦写入，就
无法按用户编辑或删除；它会按照 Cloudflare 自己的计划到期。

## 3. 我们不收集的数据

我们明确**不**收集：

- ❌ 消息内容（命令参数之外的内容）
- ❌ 个人信息（电子邮件、真实姓名、电话号码）
- ❌ IP 地址（已由 Cloudflare Workers 抽象处理）
- ❌ 服务器成员列表
- ❌ 私信内容
- ❌ 语音数据
- ❌ 图像（在内存中处理，不会存储）
- ❌ 来自 `.chara` 文件的角色名称（绝不会在卡片或嵌入消息上显示，绝不会存储）

### 图像处理

当您使用 `/extractor image` 时，您上传的图像会：
1. 在 Cloudflare 的边缘服务器上进行内存中处理
2. 被分析以提取主色
3. 处理完成后**立即被丢弃**
4. **绝不会存储**在我们的服务器上

## 5. 数据存储

### 您的数据存储在哪里

| 服务 | 存储的数据 | 位置 |
|---------|-------------|----------|
| Cloudflare KV | 偏好设置、预设收藏、首次运行提示标记、使用计数器与每日活动键（30 天 TTL），以及仅在未绑定原生速率限制的部署中使用的速率限制计数器（120 秒 TTL） | 全球边缘网络 |
| Cloudflare D1 | 社区预设、投票、审核历史、审核通知失败记录、每日提交／编辑计数器（见*数据保留*） | Cloudflare 的数据库基础设施 |
| Cloudflare Workers Analytics Engine | 命令使用遥测数据（见*使用分析*） | Cloudflare 的分析基础设施 |

所有数据都存储在 Cloudflare 的基础设施上。更多信息见
[Cloudflare 的隐私政策](https://www.cloudflare.com/privacypolicy/)。

### 数据安全

- 所有数据均通过 HTTPS 传输
- 没有服务器端会话（无状态架构）
- 通过 Discord 身份验证控制访问
- 不存储明文密码（我们不收集密码）

### 运维日志

在处理命令期间，本机器人可能会打印简短的诊断信息。其中有两处包含**您的 Discord 用户 ID**——一处在命令
开始时，一处在命令被限速时——并附带命令名称。这些日志绝不包含命令选项的值、消息内容、服务器名称、
频道 ID，或来自上传图像或 `.chara` 文件的任何内容。

持久化日志收集（Cloudflare Workers Logs）在本机器人上是**关闭**的，因此这些日志只存在于维护者当时正在
查看的实时调试日志流中，事后不会被保留。它们不是数据存储，无法被查询，并且与上文所述的使用分析相互
独立。如果我们以后启用持久化日志记录，会先更新本政策。

## 9. 儿童隐私

本机器人面向达到 Discord 最低年龄要求（13 周岁或以上，或您所在国家 / 地区规定的最低年龄）的用户。我们
不会在明知的情况下收集这些年龄限制以下儿童的数据。

如果您认为未达到最低年龄的儿童向我们提供了数据，请联系我们予以删除。

您的数据可能会在 Cloudflare 运营边缘服务器的任何国家 / 地区被处理。使用本机器人即表示您同意此项传输。
Cloudflare 为国际数据传输维持了适当的保障措施。
