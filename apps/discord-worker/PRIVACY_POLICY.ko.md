# XIV Dye Tools Discord 봇 - 개인정보처리방침

> 이 문서는 편의를 위해 제공되는 번역본입니다. 영어 버전이 원본이며, 두 버전이 다를 경우 영어 버전이 우선합니다. [English](PRIVACY_POLICY.md)

**최종 업데이트**: 2026-10-04

## 1. 소개

이 개인정보처리방침은 사용자가 저희 서비스를 이용할 때 XIV Dye Tools Discord 봇("봇", "저희")이 사용자의 정보를 어떻게 수집, 이용, 보호하는지 설명합니다.

저희는 사용자의 개인정보를 보호하고 데이터 처리 방식에 대해 투명하게 공개하는 데 최선을 다하고 있습니다. 이 봇은 팬이 만든 커뮤니티 도구이며 Square Enix와 제휴 관계가 없습니다.

### 속도 제한 데이터

- 사용자별·명령어별 카운터는 Cloudflare의 Workers 속도 제한 서비스가 **60초** 동안 보관하며 KV에는 절대 기록되지 않습니다.
- **대체 경로**: 네이티브 속도 제한 바인딩이 없는 배포 환경에서는, 대신 사용자의 Discord 사용자 ID와 명령어 이름이 포함된 키 아래 Cloudflare KV에 카운터가 보관되며 유효 기간은 **120초**입니다. 프로덕션과 베타 모두 네이티브 서비스를 바인딩하고 있으므로, 이 경로는 그곳에서는 사용되지 않습니다.
- 봇은 속도 제한을 위해 사용자의 IP 주소를 절대 확인하거나 사용하지 않습니다 — 명령어는 사용자로부터 직접 오는 것이 아니라 Discord의 서버에서 도착하기 때문에, 봇은 Discord 사용자 ID로 사용자를 식별합니다.
- 제3자는 관여하지 않습니다.

### 사용 분석

봇을 건강하게 유지하고 `/stats` 대시보드를 구동하기 위해, 저희는 사용자가 실행하는 각 명령어나 누르는 복사 버튼에 대해 다음을 기록합니다:

| 데이터 | 위치 | 보관 기간 |
|------|-------|-----------|
| 명령어 이름과 하위 명령어, 응답 여부, 그리고 문제가 발생한 경우 대략적인 실패 분류(속도 제한됨, 프리셋 또는 장터 서비스의 거부, 장터 데이터 이용 불가, 프리셋 서비스 이용 불가, 업로드된 이미지나 `.chara` 파일을 읽을 수 없음, 렌더링 실패, 알 수 없음; 오류 메시지는 절대 기록하지 않음), 처리에 걸린 시간, 서버에서 실행되었는지 DM에서 실행되었는지(`guild` / `dm` — 서버의 ID는 절대 기록하지 않음), Discord 클라이언트 언어(봇이 지원하는 여섯 언어 중 하나 또는 "기타"), 어떤 복사 버튼을 눌렀는지(hex / RGB / HSV), 그리고 Discord 사용자 ID(고유 사용자 수를 세는 용도로만 사용) | Cloudflare Workers Analytics Engine | Cloudflare의 Analytics Engine 보관 기간(작성 시점 기준 3개월) |
| 집계 카운터 — 총 명령어 수, 명령어별 횟수, 성공/실패(사용자 데이터 없음) | Cloudflare KV | 30일 (자동 TTL) |
| 하루에 사용자당 하나의 키(`usertrack:{date}:{userId}`, 값 `1`)로 일별 활성 사용자를 집계 | Cloudflare KV | 30일 (자동 TTL) |

이 기록에는 메시지 내용, 명령어 옵션 값, 서버 이름이나 채널 ID가 절대 포함되지 않습니다. Analytics Engine 데이터는 한번 기록되면 사용자별로 수정하거나 삭제할 수 없으며, Cloudflare의 일정에 따라 만료됩니다.

### 조정 기록

커뮤니티 프리셋은 조정(모더레이션)됩니다. 차단을 시행하고 조정 활동에 대한 책임성을 유지하기 위해, 저희는 다음을 보관합니다:

- **차단 기록.** 조정자가 사용자를 커뮤니티 프리셋에서 차단하면, 차단 기록에는 사용자의 Discord 사용자 ID, 또는 Discord와 연결되지 않은 XIVAuth 계정으로 웹 앱에 로그인한 경우에는 그 대신 XIVAuth ID, 차단 당시 사용자의 프리셋에 표시되던 작성자 이름, 차단을 내린 조정자와 차단을 해제한 조정자의 Discord 사용자 ID, 조정자가 밝힌 사유, 그리고 차단일과 해제일이 담깁니다.
- **조정 로그.** 각 조정 조치는 조정자의 Discord 사용자 ID, 조치 내용, 선택적 사유, 시각과 함께 기록됩니다. 프리셋에 대한 조치(승인, 거부, 되돌리기 등)에는 해당 프리셋이 명시됩니다. 차단, 차단 해제, 숨김 또는 복원에는 그 조치가 적용된 사용자도 명시됩니다.

각 기록의 보관 기간은 *데이터 보관*에 나와 있습니다.

## 3. 저희가 수집하지 않는 데이터

저희는 다음을 명시적으로 수집하지 **않습니다**:

- ❌ 메시지 내용 (명령어 매개변수 제외)
- ❌ 개인 정보 (이메일, 실명, 전화번호)
- ❌ IP 주소 (Cloudflare Workers에 의해 추상화됨)
- ❌ 서버 멤버 목록
- ❌ 다이렉트 메시지
- ❌ 음성 데이터
- ❌ 이미지 (메모리에서만 처리, 저장되지 않음)
- ❌ `.chara` 파일 (메모리에서만 처리, 저장되지 않음)
- ❌ `.chara` 파일의 캐릭터 이름 (카드나 임베드에 절대 표시되지 않으며, 저장되지 않음)

### 이미지 처리

`/extractor image`를 사용하면, 업로드한 이미지는 다음과 같이 처리됩니다:
1. Cloudflare의 엣지 서버에서 메모리 안에서만 처리됩니다
2. 주요 색상을 분석합니다
3. 처리 후 **즉시 폐기**됩니다
4. 저희 서버에 **절대 저장되지 않습니다**

### 캐릭터 파일

`/swatch` 또는 `/glamour`를 사용하면, 업로드한 `.chara` 파일은 다음과 같이 처리됩니다:
1. Discord에서 내려받아 Cloudflare의 엣지 서버에서 메모리 안에서만 읽습니다
2. 색상, 염료, 장비를 읽어 냅니다
3. 처리 후 **즉시 폐기**됩니다
4. 저희 서버에 **절대 저장되지 않습니다**

장비 이름을 표시하기 위해, `/glamour`는 파일에서 가져온 장비 모델 번호와 얼굴 소품의 ID를 저희 자체 API로 보내며, 저희 API가 이를 XIVAPI에서 조회합니다. 파일의 그 밖의 내용이나 사용자 본인 또는 Discord 계정에 관한 정보는 전송되지 않습니다.

## 5. 데이터 저장

### 사용자의 데이터가 저장되는 위치

| 서비스 | 저장되는 데이터 | 위치 |
|---------|-------------|----------|
| Cloudflare KV | 환경설정, 프리셋 즐겨찾기, 최초 실행 안내 플래그, 사용 카운터와 일별 활동 키(30일 TTL), 그리고 네이티브 속도 제한 바인딩이 없는 배포 환경에서만 사용되는 속도 제한 카운터(120초 TTL) | 글로벌 엣지 네트워크 |
| Cloudflare D1 | 커뮤니티 프리셋, 투표, 조정 기록(*조정 기록* 참고), 조정 알림 실패 기록, 일별 제출/수정 카운터 (*데이터 보관* 참고) | Cloudflare의 데이터베이스 인프라 |
| Cloudflare Workers Analytics Engine | 명령어 사용 원격 측정 (*사용 분석* 참고) | Cloudflare의 분석 인프라 |
| Discord | 저희 Discord 서버의 비공개 채널 두 곳에 올라가는 게시물. 조정 채널에는 검토가 필요한 각 프리셋, 수정 또는 미리보기 이미지가 게시됩니다: 게시물에는 프리셋(이름, 설명, 카테고리, 염료 등)과 작성자 이름이 표시되며, 미리보기 이미지의 경우에는 프리셋의 이름과 이미지가 표시되고, 조정자가 결정을 내리면 게시물이 갱신됩니다. 조정자가 사용자를 차단하면, 조정 채널에는 사용자의 작성자 이름, 사유, 숨겨진 사용자의 프리셋 수가 담긴 게시물도 올라옵니다. 조정자는 검토를 기다리는 프리셋의 목록을 작성자 이름과 함께 조정 채널에 게시할 수도 있습니다. 제출 로그 채널에는 검토 없이 게시된 각 프리셋이 작성자 이름과 함께 올라오며, 조정자가 프리셋을 승인, 거부 또는 되돌릴 때는 해당 프리셋의 이름을 밝힌 메모가 올라오고, 거부나 되돌리기의 경우에는 그 사유도 함께 올라옵니다. 이 방침의 "최종 업데이트" 날짜 이후에 올라온 게시물에는 사용자의 Discord 사용자 ID가 표시되지 않으며, 그 이전의 게시물에는 표시될 수 있습니다 | Discord의 인프라 |

그 Discord 게시물을 제외한 모든 데이터는 Cloudflare의 인프라에 저장됩니다. 자세한 내용은 [Cloudflare의 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)을 참고하세요. Discord 게시물은 [Discord의 개인정보처리방침](https://discord.com/privacy)에 따라, 조정자가 삭제하거나 사용자가 삭제를 요청할 때까지(*사용자의 권리* 참고) 그 채널에 남아 있습니다.

### 데이터 보안

- 모든 데이터는 HTTPS로 전송됩니다
- 서버 측 세션 없음 (상태 비저장 아키텍처)
- Discord 인증을 통한 접근 제어
