# XIV Dye Tools Discord 봇 - 개인정보처리방침

> 이 문서는 편의를 위해 제공되는 번역본입니다. 영어 버전이 원본이며, 두 버전이 다를 경우 영어 버전이 우선합니다. [English](PRIVACY_POLICY.md)

**최종 업데이트**: 2026-09-16

## 1. 소개

이 개인정보처리방침은 사용자가 저희 서비스를 이용할 때 XIV Dye Tools Discord 봇("봇", "저희")이 사용자의 정보를 어떻게 수집, 이용, 보호하는지 설명합니다.

저희는 사용자의 개인정보를 보호하고 데이터 처리 방식에 대해 투명하게 공개하는 데 최선을 다하고 있습니다. 이 봇은 팬이 만든 커뮤니티 도구이며 Square Enix와 제휴 관계가 없습니다.

### 속도 제한 데이터

- 사용자별·명령어별 카운터는 Cloudflare의 Workers 속도 제한 서비스가 **60초** 동안 보관하며 KV에는 절대 기록되지 않습니다.
- **대체 경로**: 네이티브 속도 제한 바인딩이 없는 배포 환경에서는, 대신 사용자의 Discord 사용자 ID와 명령어 이름이 포함된 키 아래 Cloudflare KV에 카운터가 보관되며 유효 기간은 **120초**입니다. 프로덕션과 베타 모두 네이티브 서비스를 바인딩하고 있으므로, 이 경로는 그곳에서는 사용되지 않습니다.
- 봇은 속도 제한을 위해 사용자의 IP 주소를 절대 확인하거나 사용하지 않습니다 — 명령어는 사용자로부터 직접 오는 것이 아니라 Discord의 서버에서 도착하기 때문에, 봇은 Discord 사용자 ID로 사용자를 식별합니다.
- 제3자는 관여하지 않습니다.

### 사용 분석

봇을 건강하게 유지하고 `/stats` 대시보드를 구동하기 위해, 저희는 사용자가 실행하는 각 명령어나 누르는 복사 버튼에 대해 다음을 기록합니다:

| 데이터 | 위치 | 보관 기간 |
|------|-------|-----------|
| 명령어 이름과 하위 명령어, 응답 여부, 그리고 문제가 발생한 경우 대략적인 실패 분류(속도 제한됨, 프리셋 또는 장터 서비스의 거부, 장터 데이터 이용 불가, 프리셋 서비스 이용 불가, 업로드된 이미지나 `.chara` 파일을 읽을 수 없음, 렌더링 실패, 알 수 없음; 오류 메시지는 절대 기록하지 않음), 처리에 걸린 시간, 서버에서 실행되었는지 DM에서 실행되었는지(`guild` / `dm` — 서버의 ID는 절대 기록하지 않음), Discord 클라이언트 언어(봇이 지원하는 여섯 언어 중 하나 또는 "기타"), 어떤 복사 버튼을 눌렀는지(hex / RGB / HSV), 그리고 Discord 사용자 ID(고유 사용자 수를 세는 용도로만 사용) | Cloudflare Workers Analytics Engine | Cloudflare의 Analytics Engine 보관 기간(작성 시점 기준 3개월) |
| 집계 카운터 — 총 명령어 수, 명령어별 횟수, 성공/실패(사용자 데이터 없음) | Cloudflare KV | 30일 (자동 TTL) |
| 하루에 사용자당 하나의 키(`usertrack:{date}:{userId}`, 값 `1`)로 일별 활성 사용자를 집계 | Cloudflare KV | 30일 (자동 TTL) |

이 기록에는 메시지 내용, 명령어 옵션 값, 서버 이름이나 채널 ID가 절대 포함되지 않습니다. Analytics Engine 데이터는 한번 기록되면 사용자별로 수정하거나 삭제할 수 없으며, Cloudflare의 일정에 따라 만료됩니다.

## 3. 저희가 수집하지 않는 데이터

저희는 다음을 명시적으로 수집하지 **않습니다**:

- ❌ 메시지 내용 (명령어 매개변수 제외)
- ❌ 개인 정보 (이메일, 실명, 전화번호)
- ❌ IP 주소 (Cloudflare Workers에 의해 추상화됨)
- ❌ 서버 멤버 목록
- ❌ 다이렉트 메시지
- ❌ 음성 데이터
- ❌ 이미지 (메모리에서만 처리, 저장되지 않음)
- ❌ `.chara` 파일의 캐릭터 이름 (카드나 임베드에 절대 표시되지 않으며, 저장되지 않음)

### 이미지 처리

`/extractor image`를 사용하면, 업로드한 이미지는 다음과 같이 처리됩니다:
1. Cloudflare의 엣지 서버에서 메모리 안에서만 처리됩니다
2. 주요 색상을 분석합니다
3. 처리 후 **즉시 폐기**됩니다
4. 저희 서버에 **절대 저장되지 않습니다**

### 데이터 보안

- 모든 데이터는 HTTPS로 전송됩니다
- 서버 측 세션 없음 (상태 비저장 아키텍처)
- Discord 인증을 통한 접근 제어
- 평문 비밀번호 저장 없음 (비밀번호를 수집하지 않습니다)

### 운영 로그

명령어를 처리하는 동안 봇은 짧은 진단 로그를 출력할 수 있습니다. 그중 두 가지는 명령어 이름과 함께 **사용자의 Discord 사용자 ID**를 포함합니다 — 하나는 명령어가 시작될 때, 다른 하나는 명령어가 속도 제한될 때입니다. 이 로그는 명령어 옵션 값, 메시지 내용, 서버 이름, 채널 ID, 또는 업로드된 이미지나 `.chara` 파일에서 나온 어떤 것도 절대 포함하지 않습니다.

지속적인 로그 수집(Cloudflare Workers Logs)은 봇에서 **꺼져** 있으므로, 이 로그는 그 순간 관리자가 지켜보고 있는 실시간 디버깅 스트림에서만 존재하며 이후에는 남지 않습니다. 이는 데이터 저장소가 아니고, 조회할 수 없으며, 위에서 설명한 사용 분석과는 별개입니다. 만약 저희가 지속적인 로그 수집을 활성화한다면, 이 방침을 먼저 업데이트하겠습니다.
