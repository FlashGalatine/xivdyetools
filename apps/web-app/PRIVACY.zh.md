# XIV Dye Tools — 隐私指南（网页应用）

> 本文档是为方便用户提供的翻译版本。英文版为具有法律效力的正式文本；如两者存在差异，以英文版为准。[English](PRIVACY.md)

**最后更新：** 2026-09-16 · 涵盖 **xivdyetools.app** 和 **beta.xivdyetools.app**。Discord
机器人有自己的政策：[`apps/discord-worker/PRIVACY_POLICY.md`](../discord-worker/PRIVACY_POLICY.md)。

XIV Dye Tools 在您的浏览器中运行。这些颜色工具——调色板提取、色彩和谐探索器、染剂比较、渐变生成器、
染剂混合器、无障碍检查器、预算建议和角色配色器——都在您的设备本地完成工作。除非下方某一节另有说明，
否则您上传、选择或输入的任何内容都不会被发送到任何地方，而下方的各节就是完整的清单。

## 图像与相机拍摄

- 上传、粘贴、拖入以及相机拍摄的图像永远不会离开您的设备，也不会被写入浏览器存储。它们通过浏览器的
  Canvas API 读取，仅在当前会话的页面内存中保留，并在您清除图像、关闭标签页或重新加载页面时被丢弃。
- 调色板提取工具在您选择文件的地方写着同样的话——“图像仅在浏览器中读取，绝不上传”，旁边配有一个
  挂锁图标。该提示是纯文本，不是链接；本文档需从**关于 → 隐私政策**进入才能看到。

## 角色文件（`.chara`）

- `.chara` 文件（Anamnesis、Ktisis、Brio）在您的设备上解析。其角色名称绝不会被发送到任何地方，也绝不会
  被用作预设名称、作者名称，或任何其他人可见的内容。向社区预设提交一套装扮需要您自己输入一个名称——该
  输入框默认留空，因为角色名称和文件名都是玩家可能填入真实姓名的位置。
- **有一个例外，而且它只留在您的设备上。** 如果您在未输入名称的情况下，将一套装扮或其调色板保存到本
  浏览器，保存的记录会回退使用角色的昵称，再退一步则使用 `.chara` 文件名。该名称保存在您浏览器存储中，
  与您其他已保存的收藏放在一起。它绝不会被上传，上文提到的社区路径也绝不会读取它。重命名或删除该记录，
  或清除您的网站数据，它就会消失。
- 为了给装扮组件中的装备命名，应用会向我们的 API 查询每个部位对应的物品。该请求只携带文件中的装备
  **型号编号**（每个文件约十几个小整数）——不携带文件本身、名称或颜色——物品图标则来自同一主机
  （`data.xivdyetools.app`）。

## 您的设备上存储了什么

`localStorage` 保存轻量级的偏好设置和您自己保存的内容：主题、语言、各工具的设置（包括下文的分析开关）、
收藏的染剂、已保存的调色板与收藏集，以及——如果您已登录——您的社区预设会话令牌。这里没有任何追踪
标识符。**高级设置**中的「**重置设置**」以及您浏览器的网站数据控制项可以清除这些内容。

`IndexedDB` 只保存一样东西：已获取的市场布告板价格缓存，这样同一次查询就不会被重复请求。它不保存任何
图像——旧版本的应用曾经把您最后一次在提取工具中使用的图像保存在这里，而这份副本会在您更新后首次打开
应用时被删除。您浏览器的网站数据控制项可以清除它。

## 网络访问

本应用只与以下这些第一方主机通信（网站的内容安全策略不允许任何其他连接），另外还有下方列出的第三方：

1. **市场布告板价格**（可选——「显示价格」开关）：您选择的物品 ID 以及所在的服务器或大区，会被发送到
   我们位于 `data.xivdyetools.app` 的代理，该代理再从 [Universalis](https://universalis.app) 获取数据。
2. **`.chara` 导入所需的装备名称与图标**——`data.xivdyetools.app`（见上文）。
3. **社区预设**（`api.xivdyetools.app`）：浏览时不会发送任何关于您的信息。通过 `auth.xivdyetools.app`
   使用 Discord 或 XIVAuth 登录会立即创建一条账户记录——您的提供商 ID 和用户名——无论您之后是否提交或
   投票。您提交的预设与投票会保存在该账户下，作者名称会显示在已发布的预设上。当您提交或编辑一个预设时，
   其名称与描述也可能会被发送给 Google 的 [Perspective API](https://perspectiveapi.com/) 以获取内容审核
   评分（可选——仅用于内容审核）；该请求会告知 Google 不要存储这些内容（`doNotStore`），除此之外不会
   发送任何其他信息——包括账户身份。如需移除您的账户记录与提交内容，请参阅下方的「有问题？」一节。预设
   预览图由 `shots.xivdyetools.app` 提供；头像则来自 Discord 的 CDN。
4. **分享链接**：分享链接会把您选择的染剂或颜色编码进其 URL 中。打开这样的链接就像打开任何网页一样；
   Discord 等平台上的链接预览由我们自己的 `og-worker` 渲染，它只能看到这个 URL。
5. **使用分析**（选择加入——见下一节）：`data.xivdyetools.app`。

字体为自托管。没有任何第三方分析脚本、广告或社交追踪器，也没有 Cookie。

### 会带您前往其他网站的链接

与上面的列表不同，有些按钮会把您**导航**到某个社区数据库，而不是在后台获取任何内容。角色配色器中
「在以下网站打开…」菜单在装扮部件上可以打开 [Mirapri](https://mirapri.com/)、
[Garland Tools](https://www.garlandtools.org/)、[Teamcraft](https://ffxivteamcraft.com/)、
[Gamer Escape](https://ffxiv.gamerescape.com/) 或 Lodestone；染剂结果卡片可以打开 Universalis、
Garland Tools、Teamcraft 或 [Saddlebag Exchange](https://saddlebagexchange.com/)。

这些链接中传递的只是游戏本身的物品信息——它的数字物品 ID，或该网站所用语言中的物品名称。您的信息、
您的调色板、您的角色或您的会话都不会出现在该 URL 中。它们会在新标签页中打开，并且会隐藏来源页，因此
您到达的网站不会得知您是从哪个页面过来的。一旦到了那里，您就处于别人的网站上，受他们自己的隐私政策
约束。

## 使用分析（选择加入）

分析功能**默认关闭**。只有在**高级设置 → 启用分析**打开时才会运行，并且只要您的浏览器发送了
[全球隐私控制](https://globalprivacycontrol.org/)信号，即便开关已打开，也不会运行。服务器端同样会
强制执行这一点：它只接受来自本应用自身来源的遥测数据，并且会在写入之前丢弃任何带有浏览器 `Sec-GPC`
信号的批次。关闭该开关会立即停止发送——在所有打开的标签页中都是如此——并丢弃尚未发送的所有内容。

开启后，应用会将下列小批量事件发送到我们的 API（`data.xivdyetools.app`），并存储在 Cloudflare
Analytics Engine 中：

- **工具浏览量**——打开了哪个工具、它是否是页面加载时进入的工具、来自分享链接，还是一次主动切换，
  以及该标签页在该工具上可见了多少秒。
- **染剂选取**——您从调色板抽屉或染剂网格中明确选择的染剂的数字 ID，以及您当时所在的工具。随机染剂
  按钮以及工具未接受的选取不会被计入；您的整套调色板永远不会被发送。
- **角色文件导入**——某个 `.chara` 文件是否解析成功，以及产生它的程序系列（Anamnesis、Ktisis、Brio、
  其他）。绝不包括文件本身或角色信息。
- **主题切换**——您主动切换到的主题。

每一批数据还会携带五个粗粒度维度：应用版本、环境（生产环境或测试环境）、界面语言、当前主题，以及一个
视口区间（手机 / 平板 / 桌面）。

**绝不会**与您的事件一同存储的内容：您的 IP 地址、用户代理或设备信息，任何账户、会话或客户端标识符，
Cookie，页面 URL，您所使用的颜色或图像，搜索文本，预设文本，角色或服务器名称，或任何可用于关联两次
访问的信息。服务器会丢弃除已验证事件之外关于该请求的一切；事件列表本身是一份允许清单——不在其中的任何
内容都会被丢弃。（您的 IP 会像访问任何网站一样到达我们的服务器；它接下来会发生什么，写在下一节。）

Cloudflare Analytics Engine 会将数据保留大约三个月。相关代码是开源的：
[`apps/web-app/src/services/telemetry-service.ts`](src/services/telemetry-service.ts)（浏览器发送的
内容）以及
[`apps/api-worker/src/telemetry/schema.ts`](../api-worker/src/telemetry/schema.ts)（服务器接受的内容）。

## 您的 IP 地址，以及服务器记录了什么

每个您访问的网站都会收到您的 IP 地址——这是回复得以送达您的方式。我们这边由 Cloudflare 处理，以下就是
我们对它所做的全部事情。

- **防止滥用。** 我们的 API 会在 60 秒的窗口内按 IP 统计请求次数，防止单一来源刷爆服务。计数由
  Cloudflare 自己的速率限制服务完成，我们只是把地址交给它，自己并不存储。还有一条回退路径，仅在该服务
  未接入的部署环境中使用，此时会改为在 Cloudflare KV 中，用一个包含该地址的键保存一个计数器，保留
  **120 秒**。这两条路径都不会把您的地址写入数据库，也都与您的分析事件无关。
- **您的 IP 绝不会与您做过的任何事一起存储**——不会与您的事件一起，不会与您的预设一起，也不会与您的
  投票一起。它不会被用于关联多次访问、建立画像或识别您的身份。
- **运维日志。** 我们的 Worker 在处理请求时可能会打印简短的诊断信息。持久化日志收集（Cloudflare
  Workers Logs）在我们所有的 Worker 上都是**关闭**的，因此这些信息只有在维护者正在实时查看日志流进行
  调试时才可见，事后不会被保留。如果我们以后开启持久化日志记录，会先在这里说明。Discord 机器人的日志由
  [它自己的政策](../discord-worker/PRIVACY_POLICY.md)涵盖。

## 如何验证

1. 打开开发者工具 → Network，启用「Preserve log」。
2. 使用任意带有图像或 `.chara` 文件的工具。
3. 您将不会看到任何图像上传——只有上方列出的那些请求，只有在您打开了分析功能时，才会看到
   `/v1/telemetry` 信标请求。
