# XIV Dye Tools — 隐私指南（网页应用）

> 本文档是为方便用户提供的翻译版本。英文版为具有法律效力的正式文本；如两者存在差异，以英文版为准。[English](PRIVACY.md)

**最后更新：** 2026-10-05 · 涵盖 **xivdyetools.app** 和 **beta.xivdyetools.app**。Discord 机器人有自己的政策：[`apps/discord-worker/PRIVACY_POLICY.md`](../discord-worker/PRIVACY_POLICY.md)。

XIV Dye Tools 在您的浏览器中运行。这些颜色工具——调色板提取、色彩和谐探索器、染剂比较、渐变生成器、染剂混合器、无障碍检查器、预算建议、色板匹配器和幻化查看器——都在您的设备本地完成工作。除非下方某一节另有说明，否则您上传、选择或输入的任何内容都不会被发送到任何地方，而下方的各节就是完整的清单。

## 图像与相机拍摄

- 在颜色工具中，上传、粘贴、拖入以及相机拍摄的图像永远不会离开您的设备，也不会被写入浏览器存储。它们通过浏览器的 Canvas API 读取，仅在当前会话的页面内存中保留，并在您清除图像、关闭标签页或重新加载页面时被丢弃。
- 调色板提取工具在您选择文件的地方写着同样的话——“图像仅在浏览器中读取，绝不上传”，旁边配有一个挂锁图标。该提示是纯文本，不是链接；本文档需从**关于 XIV 染色工具**（页眉中的一个按钮）→ **政策** → **隐私政策**进入才能看到。
- **有一个例外，而且只在您自己选择时才会发生。** 当您提交或编辑社区预设时，可以为其附上可选的**预览图片**。该图片会被上传到 `api.xivdyetools.app`，转换为 WebP，与该预设一起存储，并在审核员批准后通过 `shots.xivdyetools.app` 公开显示。如何移除它，见下方「网络访问」一节的第 3 项。

## 角色文件（`.chara`）

- `.chara` 文件（Anamnesis、Ktisis、Brio）在您的设备上解析。其角色名称绝不会被发送到任何地方，也绝不会被用作预设名称、作者名称，或任何其他人可见的内容。向社区预设提交一套幻化需要您自己输入一个名称——该输入框默认留空，因为角色名称和文件名都是玩家可能填入真实姓名的位置。
- **有一个例外，而且它只留在您的设备上。** 如果您在未输入名称的情况下，将一套幻化或其调色板保存到本浏览器，保存的记录会回退使用角色的昵称，再退一步则使用 `.chara` 文件名。该名称保存在您浏览器存储中，与您其他已保存的收藏放在一起。它绝不会被上传，上文提到的社区路径也绝不会读取它。重命名或删除该记录，或清除您的网站数据，它就会消失。
- 为了在幻化查看器中给装备命名，应用会向我们的 API 查询每个部位对应的物品。该请求只携带文件中的装备 **型号编号** 和面部配饰的 ID（每个文件约十几个小整数）——不携带文件本身、名称、颜色或染剂。我们的 API 会在社区游戏数据服务 [XIVAPI](https://xivapi.com/) 中查询这些编号；XIVAPI 只会收到这些编号，不会收到任何与您有关的信息。物品名称、每件物品的获取方式以及物品图标则来自同一主机（`data.xivdyetools.app`）。

## 您的设备上存储了什么

`localStorage` 保存轻量级的偏好设置和您自己保存的内容：主题、语言、各工具的设置（包括下文的分析开关）、收藏的染剂、已保存的调色板与集合、您在幻化查看器的「装备列表」中改写过的获取方式，以及——如果您已登录——您的社区预设会话令牌。这里没有任何追踪标识符。您浏览器的网站数据控制项可以清除其中的全部内容。在应用内，下列各项各自清除其中的一部分：

- **高级设置 → 重置设置**会把每个工具的设置恢复为默认值。它不会删除您已保存的内容。
- **高级设置 → 清除收藏夹**会删除您收藏的染剂。
- **高级设置 → 清除已保存的调色板**会删除您已保存的调色板。
- **管理集合 → 删除集合**会删除一个已保存的集合。
- 登出会删除会话令牌。
- 「装备列表」中的「全部重置」会删除该列表中每件装备改写过的那一行。每一行都按每件装备保存，因此共用其中某件装备的另一套幻化，也会失去该装备的那一行。

`IndexedDB` 只保存一样东西：已获取的市场布告板价格缓存，这样同一次查询就不会被重复请求。它不保存任何图像——旧版本的应用曾经把您最后一次在提取工具中使用的图像保存在这里，而这份副本会在您更新后首次打开应用时被删除。您浏览器的网站数据控制项可以清除它。

## 网络访问

本应用只与以下这些第一方主机通信（网站的内容安全策略不允许任何其他连接），另外还有下方列出的第三方：

1. **市场布告板价格**（可选——设置栏中的「启用市场布告板」开关；「预算建议」始终会加载这些价格，因为它按价格比较染剂）：您选择的物品 ID 以及所在的服务器或大区，会被发送到我们位于 `data.xivdyetools.app` 的代理，该代理再从 [Universalis](https://universalis.app) 获取数据。
2. **`.chara` 导入所需的装备名称与图标**——`data.xivdyetools.app`（见上文）。
3. **社区预设**（`api.xivdyetools.app`）：浏览时不会发送任何关于您的信息。通过 `auth.xivdyetools.app` 使用 Discord 或 XIVAuth 登录会立即创建一条账户记录，无论您之后是否提交或投票。使用 Discord 登录时，该记录保存您的 Discord 用户 ID 和您的显示名称（如果您没有显示名称，则为您的用户名）。使用 XIVAuth 登录时，该记录保存您的 XIVAuth ID 和您已验证角色的名称。如果登录时没有可用的已验证角色，该名称为“XIVAuth User”后接您的 XIVAuth ID 的前 8 个字符。如果您的 XIVAuth 账户已关联 Discord，该记录还会保存那个 Discord 用户 ID。该记录中的名称会显示为您发布的每个预设的作者，并且每次您登录时都会在所有这些预设上更新（封禁生效期间除外）。如果您之后将 Discord 关联到您的 XIVAuth 账户，那么您的预设、投票和每日限额计数会在您下次登录时转移到该 Discord 用户 ID 名下（同样，封禁生效期间除外）。您提交的预设与投票会保存在该账户下。提交预设即视为您为该预设投了一票；如果已发布的预设中已有染剂相同的预设，则您的提交会变成对该预设的一票。预设包含您在表单中填写的内容——此外，如果我们的自动检查将某次编辑的新名称或新描述扣留待审核，还包括首次此类编辑之前的版本，该版本会一直保留，直至审核员将其恢复或该预设被删除——以及上文「图像与相机拍摄」一节所述的可选预览图片。要移除预览图片，请使用该预设的编辑表单；从**我的提交**中删除预设时，其预览图片也会一并删除。当您提交或编辑一个预设时，其名称与描述也可能会被发送给 Google 的 [Perspective API](https://perspectiveapi.com/) 以获取内容审核评分（可选——仅用于内容审核）；该请求会告知 Google 不要存储这些内容（`doNotStore`），除此之外不会发送任何其他信息——包括账户身份。关于我们还保留了您的预设的哪些其他信息、保留多久，见下方*社区预设：我们保留什么*；如何删除，见*删除您的数据*。预设预览图由 `shots.xivdyetools.app` 提供；头像则来自 Discord 的 CDN。
4. **分享链接**：分享链接会把您选择的染剂或颜色编码进其 URL 中。打开这样的链接就像打开任何网页一样； Discord 等平台上的链接预览由我们自己的 `og-worker` 渲染，它只能看到这个 URL。
5. **使用分析**（选择加入——见下一节）：`data.xivdyetools.app`。

字体为自托管。没有任何第三方分析脚本、广告或社交追踪器，也没有 Cookie。

### 会带您前往其他网站的链接

与上面的列表不同，有些按钮会把您**导航**到某个社区数据库，而不是在后台获取任何内容。幻化查看器中「在以下网站打开…」菜单在幻化部件上可以打开 [Mirapri](https://mirapri.com/)、 [Garland Tools](https://www.garlandtools.org/)、[Teamcraft](https://ffxivteamcraft.com/)、 [Gamer Escape](https://ffxiv.gamerescape.com/) 或 Lodestone；染剂结果卡片可以打开 Universalis、 Garland Tools、Teamcraft 或 [Saddlebag Exchange](https://saddlebagexchange.com/)。

这些链接中传递的只是游戏本身的物品信息——它的数字物品 ID，或该网站所用语言中的物品名称。您的信息、您的调色板、您的角色或您的会话都不会出现在该 URL 中。它们会在新标签页中打开，并且会隐藏来源页，因此您到达的网站不会得知您是从哪个页面过来的。一旦到了那里，您就处于别人的网站上，受他们自己的隐私政策约束。

社区预设还可以带有一个**示例链接**，由该预设的作者选择。它指向以下网站之一的页面：Eorzea Collection、Mirapri、Reddit、X、Bluesky、Instagram、pixiv、Misskey，或《最终幻想 XIV》官方网站（其中包括 Lodestone）。本应用不会显示指向任何其他网站的示例链接。该链接由作者提供，不携带任何关于您的信息。它以同样的方式打开：在新标签页中，并隐藏来源页。

## 社区预设：我们保留什么

本节仅适用于您登录社区预设的情况。这里的一切都存储在 Cloudflare 上——账户记录由我们的登录服务（`auth.xivdyetools.app`）存储，其余由我们的预设服务（`api.xivdyetools.app`）存储——但我们 Discord 服务器中的帖子除外。

- **您的账户记录、预设与投票**（上文第 3 项）会保留，直至您删除它们或请求我们删除（见*删除您的数据*）。
- **每日限额。** 您提交的每个预设、您发送的对预设名称或描述的每次编辑，以及您上传的每张预览图片都会被计数，以便执行每日限额。该计数记录您的账户 ID、操作类型、预设和时间，并在 **30 天**后删除；删除预设不会使其提前删除。
- **我们 Discord 服务器中的帖子。** 我们的审核员在我们 Discord 服务器的两个私密频道中工作。审核频道会收到每个需要审核的预设、编辑或预览图：帖子会显示该预设（例如其名称、描述、类别和染剂）以及作者名称，若是预览图，则显示该预设的名称和该图像，并且会在审核员做出决定时更新。如果审核员封禁您，审核频道还会收到一条帖子，其中包含您的作者名称、理由以及您有多少个预设被隐藏。审核员还可以在审核频道中发布等待审核的预设列表及其作者名称。提交日志频道会收到每个未经审核即发布的预设及其作者名称，以及一条注明预设名称的说明——当审核员批准、拒绝或还原某个预设时，拒绝或还原的说明还附有理由。在 2026-10-05 之后发布的帖子不会显示您的 Discord 用户 ID；在该日期当天或之前发布的帖子可能会显示。这些帖子会保留在上述频道中，受 [Discord 的隐私政策](https://discord.com/privacy)约束，直至审核员将其删除，或直至您提出删除请求。
- **审核通知失败记录。** 如果某个预设无法发布到我们的 Discord 服务器，我们会保留一条注明该预设和错误的记录，以便审核员补发。该记录不包含任何与您的账户有关的信息。它会在审核员解决后 **30 天**删除，若无人解决则在 **90 天**后删除，若该预设被删除则立即删除。
- **封禁记录。** 如果审核员将您从社区预设中封禁，封禁记录会包含您的 Discord 用户 ID（如果您使用未关联 Discord 的 XIVAuth 账户登录，则改为我们的登录服务给您的账户 ID，这是一个随机标识符，而非您的 XIVAuth ID）。它还包含封禁时您的预设上显示的作者名称、执行封禁的审核员和解除封禁的审核员各自的 Discord 用户 ID、审核员给出的理由，以及封禁和解除封禁的日期。封禁生效期间，该记录会一直保留。封禁解除时，作者名称和理由会立即从封禁记录中清除，记录将在 **90 天**后删除。有关该封禁的审核日志条目会保留理由，如下所述。
- **审核日志。** 每一项审核操作都会连同审核员的 Discord 用户 ID、该操作、可选的理由以及时间一起记入日志。封禁、解除封禁、隐藏或恢复还会注明该操作所针对的账户，并在 **12 个月**后删除；若是隐藏或恢复，则会在其预设被删除时提前删除。其他有关某个预设的条目（例如批准、拒绝或还原）会注明该预设，并且只要该预设存在就会一直保留。

对于通过 Discord 机器人提交的预设，机器人会保留同样的记录；见[其政策](../discord-worker/PRIVACY_POLICY.md)。

## 使用分析（选择加入）

分析功能**默认关闭**。只有在**高级设置 → 启用分析**打开时才会运行，并且只要您的浏览器发送了 [全球隐私控制](https://globalprivacycontrol.org/)信号，即便开关已打开，也不会运行。服务器端同样会强制执行这一点：它只接受来自本应用自身来源的遥测数据，并且会在写入之前丢弃任何带有浏览器 `Sec-GPC` 信号的批次。关闭该开关会立即停止发送——在所有打开的标签页中都是如此——并丢弃尚未发送的所有内容。

开启后，应用会将下列小批量事件发送到我们的 API（`data.xivdyetools.app`），并存储在 Cloudflare Analytics Engine 中：

- **工具浏览量**——打开了哪个工具、它是否是页面加载时进入的工具、来自分享链接，还是一次主动切换，以及该标签页在该工具上可见了多少秒。
- **染剂选取**——您从调色板抽屉或染剂网格中明确选择的染剂的数字 ID，以及您当时所在的工具。随机染剂按钮以及工具未接受的选取不会被计入；您的整套调色板永远不会被发送。
- **角色文件导入**——某个 `.chara` 文件是否解析成功，以及产生它的程序系列（Anamnesis、Ktisis、Brio、其他）。绝不包括文件本身或角色信息。
- **主题切换**——您主动切换到的主题。

每一批数据还会携带五个粗粒度维度：应用版本、环境（生产环境或测试环境）、界面语言、当前主题，以及一个视口区间（手机 / 平板 / 桌面）。

**绝不会**与您的事件一同存储的内容：您的 IP 地址、用户代理或设备信息，任何账户、会话或客户端标识符， Cookie，页面 URL，您所使用的颜色或图像，搜索文本，预设文本，角色或服务器名称，或任何可用于关联两次访问的信息。服务器会丢弃除已验证事件之外关于该请求的一切；事件列表本身是一份允许清单——不在其中的任何内容都会被丢弃。（您的 IP 会像访问任何网站一样到达我们的服务器；它接下来会发生什么，写在下一节。）

Cloudflare Analytics Engine 会将数据保留大约三个月。相关代码是开源的： [`apps/web-app/src/services/telemetry-service.ts`](src/services/telemetry-service.ts)（浏览器发送的内容）以及 [`apps/api-worker/src/telemetry/schema.ts`](../api-worker/src/telemetry/schema.ts)（服务器接受的内容）。

## 您的 IP 地址，以及服务器记录了什么

每个您访问的网站都会收到您的 IP 地址——这是回复得以送达您的方式。我们这边由 Cloudflare 处理，以下就是我们对它所做的全部事情。

- **防止滥用。** 我们的 API 会在 60 秒的窗口内按 IP 统计请求次数，防止单一来源刷爆服务。计数由 Cloudflare 自己的速率限制服务完成，我们只是把地址交给它，自己并不存储。还有一条回退路径，仅在该服务未接入的部署环境中使用，此时会改为在 Cloudflare KV 中，用一个包含该地址的键保存一个计数器，保留 **120 秒**。这两条路径都不会把您的地址写入数据库，也都与您的分析事件无关。
- **您的 IP 绝不会与您做过的任何事一起存储**——不会与您的事件一起，不会与您的预设一起，也不会与您的投票一起。它不会被用于关联多次访问、建立画像或识别您的身份。
- **运维日志。** 我们的 Worker 在处理请求时可能会打印简短的诊断信息。持久化日志收集（Cloudflare Workers Logs）在我们所有的 Worker 上都是**关闭**的，因此这些信息只有在维护者正在实时查看日志流进行调试时才可见，事后不会被保留。如果我们以后开启持久化日志记录，会先在这里说明。Discord 机器人的日志由 [它自己的政策](../discord-worker/PRIVACY_POLICY.md)涵盖。

## 如何验证

1. 打开开发者工具 → Network，启用「Preserve log」。
2. 使用任意带有图像或 `.chara` 文件的工具。
3. 您将不会看到任何图像上传——只有上方列出的那些请求，只有在您打开了分析功能时，才会看到 `/v1/telemetry` 信标请求。本应用唯一会进行的图像上传，是您自己附加的预设预览图片（见上文「图像与相机拍摄」）。

## 删除您的数据

有些数据您可以随时自行删除，除非审核员已将您从社区预设中封禁（封禁生效期间，请向我们提出请求）：

- **预设**：在**我的提交**中删除它。其预览图片、其上的投票、有关它的审核日志条目以及它的任何审核通知失败记录会一并删除。它的每日限额计数会在 30 天后自行过期，而我们 Discord 服务器中有关它的帖子会保留，除非您向我们提出请求（见下文）。
- **投票**：再次点击该预设上的**投票**按钮。
