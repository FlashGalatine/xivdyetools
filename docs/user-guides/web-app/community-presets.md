# Community Presets

**Discover and share community dye palettes**

Community Presets lets you explore color combinations created by the community, find inspiration, and share your own creations.

> **Note**: This tool was previously called "Preset Browser" in v3.x.

> **5.0 note.** Presets are now keyed by the game's dye (stain) IDs, need **3 to 6 dyes**, carry one
> primary category plus up to two secondary categories, and can include an example link and a
> moderated preview image. The category list below is the 5.0 list; the "Community" category was
> retired.

---

## Browsing Presets

### Categories

Presets are organized by theme — one primary category plus up to two secondary ones:
- **FFXIV Jobs** - Class/job themed colors
- **Grand Companies**
- **Seasons** - Seasonal palettes
- **FFXIV Events** - Holiday and event themes
- **Aesthetics** - General looks and moods
- **Appearance** - Skin/hair/eye-matched palettes
- **Zones** - Palettes inspired by places
- **Raids & Trials**

### Sorting Options

| Sort | Description |
|------|-------------|
| **Popular** | Most votes |
| **Recent** | Recently submitted |
| **Name** | Alphabetical |

### Search

Search presets by:
- Name
- Description
- Tags

---

## Viewing a Preset

Each preset shows:
- **Name** - Creator's title
- **Description** - What it's for
- **Colors** - The dye palette (3-6 dyes)
- **Category** - Primary category, plus up to two secondary ones
- **Votes** - Community rating
- **Author** - Who created it
- **Example link / preview image** - Optional; preview images are moderated before they show

---

## Voting

Help curate the best presets:
- **Vote** - One vote per preset; click again to remove it (there are no downvotes)
- Voting requires being logged in

---

## Submitting Presets

### Requirements
- Must be logged in (Discord authentication)
- 3-6 dyes per preset
- A primary category (up to two secondary categories optional)
- Unique combination (no duplicates)
- Appropriate name and description

### Moderation
Submissions go through moderation:
1. **Automated filter** - Checks for inappropriate content
2. **Community voting** - Helps surface quality
3. **Manual review** - For flagged content

### Rate Limits
- 10 submissions per day
- Helps maintain quality

---

## Using Preset Dyes

For any dye in a preset:
- **Add to Favorites** - Save individually
- **Add to Collection** - Group with your dyes
- **Open in Comparison** - See side-by-side
- **See Harmonies** - Find more options

---

## Duplicate Detection

If you try to submit a preset that already exists:
- You'll see a notification
- You can vote on the existing preset instead
- This keeps the library clean

---

## Tips

- **Descriptive names** help others find presets
- **Good descriptions** explain the use case
- **Vote honestly** to help quality rise
- **Report issues** if you see inappropriate content
