# Dye Maintainer Tool (removed)

> **The Dye Maintainer GUI (`apps/maintainer`) was removed on 2026-07-31** as part of the Monorepo 2.0 consolidation.
>
> - **The canonical dye-addition procedure is now [adding-dyes.md](./adding-dyes.md).**
> - The vocabularies and validation the tool provided live in `@xivdyetools/core` (`src/config/dye-vocabulary.ts` + its data-invariant tests) and run in CI.
> - Rationale, audit findings (including the tool's data-destroying save path), and the full deprecation record: `DEPRECATIONS.md` and `docs/research/monorepo-2.0/03-maintainer-deprecation.md`.
> - The tool's source remains available in git history prior to this date.
