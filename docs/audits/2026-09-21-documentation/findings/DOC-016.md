# DOC-016: the oauth setup guide omits `XIVAUTH_CLIENT_SECRET` from its Secrets list
**Severity:** MEDIUM · **Deploy unit:** oauth · **Baseline:** working tree = `main` `59572c0` + this branch's three spelling commits

## Location
- `docs/projects/oauth/overview.md:200-203` — the **Secrets:** block gives `wrangler secret put DISCORD_CLIENT_SECRET` and `wrangler secret put JWT_SECRET`, and nothing else.

## Evidence
- `apps/oauth/wrangler.toml:75` — the worker's own comment lists three: `DISCORD_CLIENT_SECRET, JWT_SECRET, XIVAUTH_CLIENT_SECRET`.
- `apps/oauth/src/types.ts:64` declares it, and `src/handlers/xivauth.ts:158-159` reads it to add `client_secret` to the token exchange — XIVAuth confidential-client mode.
- An operator following the guide provisions two of the three and XIVAuth confidential-client logins fail, with the guide giving no hint that a third secret exists.

## Fix
- Add `wrangler secret put XIVAUTH_CLIENT_SECRET` with a note that it is optional and only needed for XIVAuth confidential-client mode, matching `types.ts:64`.
