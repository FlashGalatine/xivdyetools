# DOC-018: the moderation runbook never mentions banning an XIVAuth-only author
**Severity:** MEDIUM · **Deploy unit:** moderation-worker · **Baseline:** working tree = `main` `59572c0` + this branch's three spelling commits

## Location
- `docs/operations/MODERATION.md:37,100` — `/preset ban_user user:<discord_user>` and the `unban_user` twin.

## Evidence
- `apps/moderation-worker/scripts/register-commands.ts:93-98` — the `user` option is `type: OptionType.STRING` with `autocomplete: true` and the description "User to ban (search by username)". It is a typed search box, not a Discord mention picker, and the `<discord_user>` placeholder implies otherwise.
- `apps/presets-api/src/middleware/ban-check.ts:26-34` — XIVAuth-only accounts have no Discord ID and are bound by the oauth worker's internal UUID; `preset.ts:564` already switches the ban label between "Discord ID" and "XIVAuth ID". The capability exists; the runbook does not mention it.
- A moderator reading this runbook would conclude an XIVAuth-only author cannot be banned.

## Fix
- Note that `user` is a username search, and add a line covering XIVAuth-only authors (target by the UUID shown in the preset's author field).
