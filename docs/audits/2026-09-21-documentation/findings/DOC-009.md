**Severity:** LOW · **Deploy unit:** repo-wide · **Baseline:** working tree = `main` `59572c0` + this branch's three spelling commits

## Location
- `docs/architecture/dependency-graph.md` — the Consumer Applications table's Runtime Dependencies rows for `moderation-worker`, `og-worker` and `image-worker`.

## Evidence
- Those three `package.json` files carry `@cloudflare/workers-types` under `dependencies` (`^5.20260911.1`), not `devDependencies`.
- `discord-worker` and `presets-api` have it under `devDependencies`, where the table correctly omits it — so the table is right elsewhere and wrong only for these three.

## Fix
- Add it to those three rows, or move the dependency to `devDependencies` in the three manifests if the runtime placement is itself the mistake. The manifests decide which.
