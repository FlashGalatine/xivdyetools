# [DEAD-023]: `public/og/<tool>/` — 18 static per-tool OpenGraph cards (2.06 MB) shipped on every deploy but never linked; og-worker serves these dynamically

## Category
Orphaned File (asset)

## Location
- `apps/web-app/public/og/{accessibility,budget,comparison,extractor,gradient,harmony,mixer,presets,swatch}/default.png` + `default-x.png` — 18 files, **2,059,669 bytes**
- (KEEP: `public/og/default.png` 129,843 B and `public/og/default-x.png` 87,145 B — linked from `src/index.html:31,:46`)

## Evidence
- `grep -rn "og/<tool>/default" apps/web-app/src apps/web-app/public/_headers apps/web-app/vite-plugin-beta-branding.ts` → **0** references to any per-tool path.
- Per-tool cards are generated by **og-worker**: `apps/og-worker/src/index.ts:295` `app.get('/og/:tool/default.png')`, with `OG_IMAGE_BASE_URL = https://og.xivdyetools.app/og` (`wrangler.toml:76`; beta `og-beta.xivdyetools.app`). og-worker's zone routes are `xivdyetools.app/<tool>/*` (`wrangler.toml:61-69`), **not** `/og/*`, so nothing routes a crawler to `xivdyetools.app/og/<tool>/…`.
- `git log -S"og/harmony/default" -- apps/web-app/src apps/web-app/index.html` → **no commit** in the web-app ever emitted such a link. The files were added by `591414f` (2026-08-12, "move social cards out of /assets/") — i.e. moved from one dead location to another.
- Memory note from the OG-card split confirms the design: og-worker owns the nine tool cards; web-app owns only the site-root card.

## Why It Exists
Pre-og-worker, the web-app hosted static per-tool cards. When og-worker took over dynamic generation the static set was kept (and later relocated) rather than deleted.
