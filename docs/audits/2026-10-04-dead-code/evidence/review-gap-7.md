## Cross-cutting recommendation
Add a "next major" register (like DEAD-018) listing 01-06, bundled so each major is cut once: logger 3.0.0 (01), worker-kit 2.0.0 (03), types 4.0.0 (04, 06b), core 6.0.0 (02b, 06a, plus C1 / DEAD-018 items), bot-logic 5.0.0 (02a), auth 3.0.0 (05, optional). Ordering: bot-logic 02a before core 02b; core 06a before types 06b. Any round-1 "REMOVE now" row for these symbols should be downgraded to "REMOVE at major <pkg>".

## Rejected
- Immediate removal in a minor/patch: rejected (published API; no in-repo consumer is insufficient).
- Deleting DelegatingLogger independently: rejected; it is the type behind child() and implements the interface.
- DEAD-020 classification for Upstash: rejected; no selector in the repo constructs it.
- Stoat consumers of these symbols: none found beyond its own upstash config fields (config.ts:10-12).
