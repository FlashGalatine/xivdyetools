# I18N-006: `/extractor image` count line has one plural form — "1 Farben" / "1 couleurs" when K-means collapses to a single cluster
**Tier:** P3 (edge path) · **Locale(s):** en de fr · **Deploy unit:** discord-worker + bot-logic key · **Generated?** no

## Location
- `apps/discord-worker/src/handlers/commands/extractor.ts:586` — `t.t('card.colours', { n: matches.length })`.
- bot-logic `card.colours` = `{n} colours` / `{n} Farben` / `{n} couleurs` — a single form, via `t.t()` not `.tc()`.

## Evidence
- `matches.length === 1` is reachable on a near-monochrome upload (empty K-means clusters are dropped). `preferences.ts:446-448` already special-cases `count === 1`, and `.tc()` exists for exactly this.

## Fix
- **Keep the bare `card.colours` key** (removing a bot-logic locale key is a MAJOR; `translator.ts:105-106` already falls back to it) and add `card.colours_one` / `_other` (×6; ja/ko/zh identical strings) and call `t.tc('card.colours', n, { n })`. Land after I18N-003 so the French rule is already right.
