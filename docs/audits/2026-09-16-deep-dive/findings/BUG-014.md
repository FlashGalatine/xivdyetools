# BUG-014: `PATCH /presets/refresh-author` binds `auth.userName` with no fallback; an undefined bind makes D1 throw a 500
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** presets-api · **Covered by test?** no

## Location
- `apps/presets-api/src/handlers/presets.ts:344-350` — `.bind(auth.userName, auth.userDiscordId)`; `userName` is optional (`packages/types/src/auth/provider.ts:39`)
- `apps/presets-api/src/handlers/presets.ts:934,1181` — siblings use `|| 'Unknown User'` / `?? ''`

## Evidence
- Web path sets `global_name || username` (`auth.ts:367`) and `username` is a required claim, and the bot never calls this route — so only a malformed/legacy token reaches it
- Reviewer row `presets-api-03`; Opus pass confirmed LOW

## Fix
- `auth.userName ?? ''` (or reject with 400 when empty) to match the siblings; one-line change + a test with a name-less token
