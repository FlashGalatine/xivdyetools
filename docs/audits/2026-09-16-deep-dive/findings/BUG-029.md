# BUG-029: `add-to-collection-menu` off-screen check assumes a 200 px menu while its CSS allows up to 256 px
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** web-app · **Covered by test?** no

## Location
- `apps/web-app/src/components/add-to-collection-menu.ts:53,61-66` — `menuWidth = 200` vs `min-w-48 max-w-64`

## Evidence
- Reviewer row `webapp-modals-04`; up to 56 px can render off-viewport near the right edge

## Fix
- Measure `getBoundingClientRect().width` after first paint, or clamp with `max-w-64`'s 256
