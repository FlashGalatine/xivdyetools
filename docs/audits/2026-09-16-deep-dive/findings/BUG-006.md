# BUG-006: Bot `/swatch` card drops the L/R eye marker on off-grid rows, so off-grid heterochromia renders two identical 'EYES · OFF GRID' rows
**Severity:** MEDIUM · **Type:** Edge case · **Deploy unit:** bot-logic (publish) → discord-worker (deploy) · **Covered by test?** no

## Location
- `packages/bot-logic/src/commands/swatch.ts:248-254` — `if (!offGrid && (slot.slot === 'leftEye' || …)) addr += '·L' | '·R' | '·LR'`; the suffix is skipped whenever `offGrid`
- `packages/bot-logic/src/commands/swatch.ts:115-125` — `SLOT_KEYS` maps both eyes to `card.slotEyes`, so the label cannot disambiguate either

## Evidence
- Reproduction: a `.chara` with `eyesShareIndex === false` whose eye colours are both off-grid → two rows labelled EYES / OFF GRID with different swatches and no left/right cue
- Reviewer row `pkg-svg-bot-logic-01`; Opus pass confirmed

## Fix
- Append the `·L`/`·R`/`·LR` marker regardless of `offGrid` (put it on the label or after the OFF GRID token); add a heterochromia-off-grid case to `swatch.test.ts`
- Two sprints: publish `@xivdyetools/bot-logic`, then deploy discord-worker
