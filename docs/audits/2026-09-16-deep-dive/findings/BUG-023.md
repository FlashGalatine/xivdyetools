# BUG-023: `market-board.ts` refresh status uses a raw `setTimeout` that `destroy()` cannot cancel
**Severity:** LOW · **Type:** Resource · **Deploy unit:** web-app · **Covered by test?** no

## Location
- `apps/web-app/src/components/market-board.ts:376-378` — `setTimeout(() => statusMsg.textContent = '', 3000)` bypasses the component's `safeTimeout`

## Evidence
- Reviewer row `webapp-tools-b-05`; fires after teardown and writes to a detached node

## Fix
- Use `this.safeTimeout(...)`
