- `apps/oauth/src/handlers/token.ts:101-190` — POST /revoke: 401 for a missing or invalid Bearer token, 200 `revoked: true`, 503 `revoked: false` when the KV write fails (BUG-050), 200 `revoked: false` with a `note` when there is no KV or no jti, 500 on an exception
- `apps/oauth/src/handlers/xivauth.ts:58-59,77` — GET /xivauth, GET /xivauth/callback, POST /xivauth/callback

## Fix
- After GET /auth/me, add a POST /auth/revoke section (Bearer header; 200 revoked:true; 200 revoked:false + note when there is no blacklist or jti; 401; 503 when the KV write fails; 500). Add GET /auth/xivauth and GET/POST /auth/xivauth/callback sections that mirror the Discord ones.
