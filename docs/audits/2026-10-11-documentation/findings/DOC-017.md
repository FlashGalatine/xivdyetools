# DOC-017: algorithms.md gives `classifyBandTier` the wrong parameter order
**Severity:** MEDIUM · **Deploy unit:** core · **Baseline:** production `16a6123f` = HEAD `42c35e87` for code (checked 2026-10-11)

## Location
- `docs/projects/core/algorithms.md:226` — "`classifyBandTier(distance, context, method)` returns the `BandTier`;"

## Evidence
- `packages/core/src/config/band-vocabulary.ts:158-165` — `export function classifyBandTier(value: number, method: BandMethod, context: BandContext)`; the body reads `BAND_VOCABULARY[context][method]`
- Swapped call: classifyBandTier(d, 'match', 'ciede2000') reads BAND_VOCABULARY['ciede2000'], which is undefined, so destructuring ['match'] throws a TypeError (it is also a compile-time type error)
- `packages/svg/CLAUDE.md:56` and packages/core/CHANGELOG.md:849 both give the correct order `classifyBandTier(value, method, context)`

## Fix
- Change it to `classifyBandTier(distance, method, context)`.
