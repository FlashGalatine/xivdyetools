# DOC-021: local-setup.md's single-test example points at a path that matches no test file
**Severity:** MEDIUM · **Deploy unit:** repo-wide · **Baseline:** production `16a6123f` = HEAD `42c35e87` for code (checked 2026-10-11)

## Location
- `docs/developer-guides/local-setup.md:73` — "pnpm --filter @xivdyetools/core exec vitest run src/services/DyeService.test.ts"

## Evidence
- `git ls-files packages/core | grep DyeService.test` → only packages/core/src/services/__tests__/DyeService.test.ts
- vitest treats positional args as path substrings. 'src/services/DyeService.test.ts' is not a substring of 'src/services/__tests__/DyeService.test.ts', so no file matches and vitest exits 1 ('No test files found'; passWithNoTests is off)
- CLAUDE.md (Working in this checkout → The gate): a single-file run needs `--coverage.enabled=false`, or a green subset run still exits 1 on coverage thresholds

## Fix
- pnpm --filter @xivdyetools/core exec vitest run src/services/__tests__/DyeService.test.ts --coverage.enabled=false
