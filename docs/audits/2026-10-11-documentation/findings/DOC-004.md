# DOC-004: web-app user guides misstate privacy facts: deletion via public GitHub issues, an incomplete stored-data list, a stale sign-in quote
**Severity:** MEDIUM · **Deploy unit:** web-app · **Baseline:** production `16a6123f` = HEAD `42c35e87` for code (checked 2026-10-11)

## Location
- `docs/user-guides/web-app/faq.md:163` — "Yes, contact us via GitHub issues or Discord to request data deletion."
- `docs/user-guides/web-app/faq.md:155` — "Discord ID (if logged in)"
- `docs/user-guides/web-app/community-presets.md:85` — "*We store your display name and provider ID. No character data, no email, nothing sold.*"

## Evidence
- `apps/web-app/PRIVACY.md:258-266` — self-service deletes, then for anything else ask privately by email (line 261) or Discord DM, and line 265: "Please don't ask in a public GitHub issue: that would publish the very details you want removed."
- `apps/web-app/PRIVACY.md:82-86` — a Discord record holds the Discord user ID + display name; an XIVAuth record holds the XIVAuth ID and the verified character's name, plus a linked Discord user ID if there is one
- `apps/web-app/src/locales/en.json:1018` — preset.privacyNote (rendered by signin-modal.ts:62) reads "Signing in creates an account record: your Discord or XIVAuth ID and a name … With XIVAuth, that name is your verified character's … No email, nothing sold." It does not say "No character data".

## Fix
- Point the FAQ deletion answer at the Privacy Guide's deletion section: self-service delete first, then email or DM, never a public issue. List the stored data as 'your Discord or XIVAuth ID and a display name (your verified character's name with XIVAuth)'. Quote en.json preset.privacyNote verbatim in community-presets.md.
