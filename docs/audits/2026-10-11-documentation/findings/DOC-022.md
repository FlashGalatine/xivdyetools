## Evidence

- `apps/moderation-worker/scripts/register-commands.ts:86-92,100-106` — `user` is type STRING with autocomplete ('search by username'), not a USER option. The value is the author id: a Discord snowflake or an XIVAuth UUID (src/index.ts:471-480,505-511 label choices `discord:`/`xivauth:`).
- `apps/moderation-worker/src/services/ban-service.ts:487-491` — XIVAuth-only targets are bannable (UUID also stored in xivauth_id). src/handlers/commands/preset.ts:526-533 labels the confirmation field 'Discord ID' or 'XIVAuth ID'.

*Narrowed at verification:* Narrowed: line 136 ('Matches by username or Discord ID') is not wrong. searchBannedUsers (ban-service.ts:189-194) matches username, discord_id OR xivauth_id, so the doc only omits XIVAuth ID and was not misstating it.

## Fix
- Replace :15 with `/preset moderate` (pending/approve/reject/stats) plus the review-embed Approve/Reject/Revert buttons. Write `user:<username search>` and pick a choice; mention the discord:/xivauth: labels and the Discord ID / XIVAuth ID confirmation field. Fix the @mention examples at :54/:111.
