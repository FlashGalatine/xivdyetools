# DOC-013: presets-api's moderation docs say a missing PERSPECTIVE_API_KEY lets the word list decide alone; every submission is queued instead
**Severity:** MEDIUM · **Deploy unit:** presets-api · **Baseline:** production `16a6123f` = HEAD `42c35e87` for code (checked 2026-10-11)

## Location
- `docs/projects/presets-api/moderation.md:31-33` — "The *only* thing that skips this tier is an **absent** `PERSPECTIVE_API_KEY`, in which case the local word list alone decides"
- `docs/projects/presets-api/overview.md:187` — "Requires `PERSPECTIVE_API_KEY`; **fail-closed** — with a key set, an error or timeout also queues" (the no-key case is never described)
- `docs/projects/presets-api/overview.md:196-206` — flow diagram: Perspective "[clean]" leads to "status = 'approved' (auto-approved)", with no branch for a missing key

Also: docs/architecture/security-trade-offs.md:290 ("PERSPECTIVE_API_KEY unset ─► local list alone decides"), docs/architecture/security-trade-offs.md:312 ("the local list alone decides"), DEPRECATIONS.md:31-38 ("deleting the key alone turns moderation off" / "moderateContent then passes anything the local word list does not match": stale since 2.4.0 shipped the pending default)

## Evidence
- `apps/presets-api/src/services/moderation-service.ts:376-386` — `if (!perspectiveResult)` returns `passed: false, method: 'unscored'`, flaggedReason 'No external moderation scorer configured — queued for manual review' (FINDING-019)
- `apps/presets-api/src/handlers/presets.ts:1039` — `const status = moderationResult.passed ? 'approved' : 'pending'`, so `unscored` lands as pending
- `apps/presets-api/CHANGELOG.md:137-138` (under [2.4.0], line 101) — "No scorer, no auto-approve (FINDING-019). Without PERSPECTIVE_API_KEY, new presets and text edits are queued for review (method unscored)"

## Fix
- Say that a missing key reports locally clean text as `unscored` and queues it for a moderator, and add the no-key branch to the overview flow diagram. Rewrite moderation.md:33-34: deleting the key now sends every submission to manual review rather than turning moderation off.
