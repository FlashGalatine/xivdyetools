# DOC-001: `environment-variables.md` marks three presets-api secrets "Required: No" that production refuses to start without
**Severity:** HIGH · **Kind:** WRONG · **Deploy unit:** presets-api · **Baseline:** `0fec18f4` (served by every production deploy workflow, = `origin/main`), checked 2026-09-18

## Location
- `docs/developer-guides/environment-variables.md:182` — `MODERATOR_IDS` "No"
- `docs/developer-guides/environment-variables.md:183,186` — `BOT_SIGNING_SECRET`, `INTERNAL_WEBHOOK_SECRET` "No"
- `docs/developer-guides/environment-variables.md:190-198` — the `wrangler secret put` block omits the last two

## Evidence
- `apps/presets-api/src/utils/env-validation.ts:43-49` requires `MODERATOR_IDS` in every environment; `:97-99,131-133` require the other two when `ENVIRONMENT === "production"`.
- `apps/presets-api/src/index.ts:60-79` runs `validateEnv` per request and answers `500 "Service misconfigured"` to everything in production on failure — provisioning from this page is a whole-API outage.
- Reviewer candidates: DO-02, DO-03 (verdicts in `../evidence/verify-*.md`).

## Fix
- Set `MODERATOR_IDS` to "Yes", the other two to "Yes (production)", and add both to the `wrangler secret put` block.
