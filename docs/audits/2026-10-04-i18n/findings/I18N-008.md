# I18N-008: German `glamour.row.fixed*` hardcodes neuter "das" after an item name of any gender
**Tier:** P3 · **Locale(s):** de · **Deploy unit:** apps/web-app · **Generated?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/locales/de.json:1369-1371` — "Statt {name}, das diese Farbstoffe nicht annimmt" / "…, das sich nicht projizieren lässt" / "…, das dieser Charakter nicht tragen kann"

## Evidence
- `{name}` is any item, so a masculine or feminine name ("Gürtel", "Hose") gets the wrong relative pronoun. The English is "which …". The bot has the same pattern (I18N-018).

## Fix
- Rephrase without a pronoun, e.g. "Statt {name} (nimmt diese Farbstoffe nicht an)".
