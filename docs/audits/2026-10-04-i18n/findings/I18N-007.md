# I18N-007: Glamour Reader counts have no singular form: "1 dyes", "Same look as 1 other items", "1 pieces"
**Tier:** P3 · **Locale(s):** en de fr (keys in all six) · **Deploy unit:** apps/web-app · **Generated?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/glamour-block.ts:518` — `swatch.equipCount` "{channels} channels · {dyes} dyes" (`en.json:1255`)
- `glamour-block.ts:946`/`:964` — `glamour.row.twins` with n = 1 for a pair (de "1 weitere Gegenstände", `de.json:1380`); `glamour-sheet.ts:143` — `glamour.sheet.sub` "{n} pieces" (`de.json:1400` "{n} Teile")
- `glamour-block.ts:1497-1501` — the footnote tests `=== 1`, so fr reads "0 pièces portées sont non teintes"

## Evidence
- Only the verdict segments pick a form, through `phrase(n, key_one, key_other)` (`glamour-block.ts:1436`); these four sites pass the count into one string.

## Fix
- Add `_one`/`_other` in all six locales for each key and select with `Intl.PluralRules(lang)` through the existing helper (fr treats 0 as singular).
