# BUG-143: emitted-glyphs.ts scanner fails open on \u escapes in literals and on a keyword-preceded regex (return /'/)
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** packages/svg · **Covered by test?** no · **Origin:** MAIN · **Other units:** apps/discord-worker (font-coverage gate)

## Location
- `packages/svg/src/emitted-glyphs.ts:141`

## Evidence
- Reproduction: add `${n}★` to a card -> scanEmittedGlyphs omits U+2605 -> discord-worker font-coverage.test.ts passes -> tofu ships
- Inside a literal, :141-143 skips every backslash pair, so '★' records nothing. At :97, prev 'n' from `return` makes `/` division, so a following quote opens a string and desyncs; an even number of flips escapes the EOF throw at :169. The input is future card source, which is exactly what this gate judges, so it is latent but live. No current scanned source triggers it: the only \u hits are escapeXml's regex strings at base.ts:19-21.
  - Checked: packages/svg/src/emitted-glyphs.ts:97,141-143,169; apps/discord-worker/src/services/font-coverage.test.ts:134-152 (scans svg/src + bot-logic/src/commands); git grep -F '\u' in those roots -> only base.ts:19-21
- Origin: git diff --stat 8ecb878f HEAD -- packages/svg is empty; emitted-glyphs.ts:97/141 identical at 8ecb878f

## Fix
- Decode \uXXXX / \u{...} escapes in literals but drop surrogates (D800-DFFF) and noncharacters (FFFE/FFFF), or exempt RegExp-source strings, so base.ts:19-21 does not break the gate. Treat a preceding keyword (return/typeof/case/in/of/void/throw/yield/await) as regex start.
Needs an svg publish (test-time only consumers via workspace).
