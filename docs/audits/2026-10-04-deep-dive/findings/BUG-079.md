# BUG-079: budget-tool.ts onMount: forces and persists the global market.showPrices=true and never restores it
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** overlaps BUG-027 (sidebar desync)

## Location
- `apps/web-app/src/components/budget-tool.ts:292`

## Evidence
- Reproduction: Prices off -> open Budget -> switch to Harmony: prices are fetched and shown, and the setting survives a reload.
- setShowPrices(true) goes to ConfigController.setConfig('market', {showPrices}) (market-board-service.ts:251-257), which persists to localStorage. destroy (:303-311) never restores the old value, so a user who turned prices off has them on, and fetching, in Harmony/Mixer/Comparison after one Budget visit. This is distinct from BUG-027, which covers the sidebar not re-reading the value; this covers the persisted write.
  - Checked: budget-tool.ts:292; market-board-service.ts:251-257; config-controller.ts:306
- Origin: git show 8ecb878f:budget-tool.ts:292 `this.marketBoardService.setShowPrices(true)`

## Fix
- Fetch Budget's prices regardless of showPrices without writing the preference, or save the old value and restore it in destroy.
