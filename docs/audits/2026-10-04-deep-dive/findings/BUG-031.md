# BUG-031: community-preset-service response cache never invalidated after delete/edit/submit
**Severity:** MEDIUM · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/services/community-preset-service.ts:262`

## Evidence
- Reproduction: Open presets (caches list), delete own approved preset -> loadPresets() with same query returns cached list still showing it for up to 5 min
- SimpleCache (5 min TTL) keys presets:<query>/preset:<id>; no non-test code calls clearCache() (hybrid-preset-service.ts:460 wrapper has no caller), votes only delete preset:/vote: keys, so preset-tool's post-delete loadPresets() reuses the cached list.
  - Checked: community-preset-service.ts:262-268 cache hit, :83 CACHE_TTL 5 min, :428-429/:480-481 only per-id deletes
- Second, independent check (severity MEDIUM): I could not refute this finding. `request()` returns any cached `presets:<query>` entry for up to 5 minutes (community-preset-service.ts:83, :262-268, :325). After a delete or edit, preset-tool.ts:986 and :953 call `loadPresets()` again with the same search, sort and limit (:593-597), so `hybridPresetService.getPresets` builds the same key (hybrid-preset-service.ts:296-305) and gets the cached list back. Neither `presetSubmissionService.deletePreset` nor `editPreset` touches that cache. Only the vote paths delete keys, and only `preset:<id>` and `vote:<id>` (:428-429, :480-481). Nothing outside tests calls `clearCache()` or the hybrid wrapper at :459-460. A page reload, or the 5 minutes running out, clears it, so the result is a wrong list for a while on an edge path, with no data loss. That keeps it at MEDIUM. LOW would be arguable because the problem fixes itself.
- Origin: git log 8ecb878f..HEAD -- apps/web-app/src/services/ is empty; git grep '.clearCache()' finds no caller of the community/hybrid clearCache

## Fix
- Clear the community cache (or delete the presets:* prefix plus preset:<id>) on successful delete/edit/submit/vote; web-app only.
