# BUG-097: image-zoom-controller.ts touch handlers: a second finger does not cancel the drag, so a two-finger gesture commits a colour sample on lift
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/components/image-zoom-controller.ts:714`

## Evidence
- Reproduction: Extractor with image loaded on a touch device, place two fingers (pinch), lift one -> image-sampled emitted at the lifted finger's point, replacing the picked colour
- touchstart (image-zoom-controller.ts:710-719) returns on touches.length!==1 and leaves isDragging=true from the first finger. touchmove bails on 2 touches, then the first lifted finger's touchend (:744-760) passes the isDragging guard and calls sampleColorAtArea at that point. The card's touch-action:none (extractor-tool.ts:874) means a pinch attempt has no browser effect, only an unintended sample.
  - Checked: image-zoom-controller.ts:710-719, :721-742, :744-760; extractor-tool.ts:874 touch-action:none
- Origin: git diff 8ecb878f HEAD -- image-zoom-controller.ts empty

## Fix
- When touchstart sees touches.length>1, set isDragging=false, emit loupe-end if hasDraggedPastThreshold, and reset the threshold flag.
