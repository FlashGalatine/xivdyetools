# BUG-094: gradient-tool.ts result-card slot picker (Set as End/Start) has no same-dye guard, and endpoint rows render cards
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/components/gradient-tool.ts:1990`

## Evidence
- Reproduction: With start A and end B, open the Start row's card, choose slot 2 (End): start === end === A, the ramp is flat and the share link carries start=A&end=A
- calculateInterpolation pushes the start and end dyes as the endpoint rows' matchedDye. renderIntermediateMatches renders a card for every row with showSlotPicker=true, and compact cards still show actions. add-mixer-slot-2 then sets selectedDyes[1]=startDye with none of selectDye's sameDyeWarning or swap guard. The transform-gradient half of the claim cannot be reached: cards only exist when both endpoints are set, so that path always takes slotsFull.
  - Checked: gradient-tool.ts:1812-1820 endpoint rows have matchedDye = endpoint dye; 1980-1999 showSlotPicker=true writes selectedDyes[1] with no check; result-card.ts:1730-1760 compact cards still render the slot picker; selectDye at 2654-2665 and 2708-2713 has the guard
- Origin: git log 8ecb878f..HEAD -- gradient-tool.ts is empty, so the same code is on main

## Fix
- Send add-mixer-slot-1/2 through the same swap/sameDyeWarning logic as selectDye (for example set activeEndpoint and call selectDye), or turn off showSlotPicker on the endpoint rows.
