# BUG-078: budget-tool.ts ignores persisted ConfigController displayOptions at mount; showHue/Stain/Spectrum always reset to true
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/budget-tool.ts:201`

## Evidence
- Reproduction: Uncheck Hex (or Hue) in the sidebar while in Harmony, then open Budget: the target card still shows Hex or Hue.
- The constructor reads only the local v3_budget_show_* keys (221-228). The sidebar broadcast (config-sidebar.ts:862-873) writes only the ConfigController budget config, and subscribe does not replay, so the comment at 173 ('ConfigController replays them') is false. LOW: only target-card display rows are wrong (cosmetic).
  - Checked: budget-tool.ts:173-176 and 221-228; config-controller.ts:346-362 subscribe has no replay; config-sidebar.ts:862-873 broadcast
- Origin: git diff --stat 8ecb878f HEAD -- budget-tool.ts, config-sidebar.ts: empty

## Fix
- In the constructor or onMount, apply getConfig('budget').displayOptions via applyDisplayOptions (or call setConfig once with it) before the first render of the target overview. Web-app only.
