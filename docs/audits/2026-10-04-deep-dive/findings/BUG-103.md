# BUG-103: swatch-tool registers its window resize listener with this.on in onMount; BaseComponent.update() unbinds it on a language switch and never re-adds it
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/swatch-tool.ts:405`

## Evidence
- Reproduction: Switch language (swatch subscribes LanguageService -> update()), then resize across 768px -> updateSwatchLayout never runs, so the inline 26/44px cell sizing and the direction stay stale until a palette reload or a remount
- The listener lives in the listeners map that update() clears. Nothing re-registers it, and nothing remounts the tool on a language or viewport change.
  - Checked: base-component.ts:148-160 calls unbindAllEvents then the empty bindEvents (swatch 357-359); onMount does not re-run; No remount on language or breakpoint change: v4-layout.ts:338 only refreshes the title; v4-layout-shell.ts:797 matchMedia only toggles the shell's own state
- Origin: git diff 8ecb878f HEAD -- swatch-tool.ts base-component.ts is empty; 8ecb878f:swatch-tool.ts:405 has the same this.on(window,'resize',...)

## Fix
- Register the resize listener in bindEvents(), or via this.subs with a manual add/removeEventListener pair
