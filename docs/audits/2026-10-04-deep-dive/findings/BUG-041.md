# BUG-041: preview-image.ts puts a raw <@id> mention in the embed footer and drops the preset ID
**Severity:** LOW · **Type:** Logic · **Deploy unit:** apps/discord-worker · **Covered by test?** no · **Origin:** MAIN · **Other units:** N/A

## Location
- `apps/discord-worker/src/handlers/buttons/preview-image.ts:261`

## Evidence
- Reproduction: Moderator clicks Approve on a preview-image post: the footer reads 'Preview image approved by <@1234...>' and the ID line is gone.
- preview-image.ts:261 builds `<@id>` and :277-291 puts it into the embed footer, where Discord does not resolve mentions. The same edit replaces the original footer `ID: <presetId>` set at index.ts:354, so the resolved message loses the preset id.
- Origin: git show 8ecb878f:apps/discord-worker/src/handlers/buttons/preview-image.ts:261 and :291 are identical.

## Fix
- Keep `ID: <presetId>` in the footer and move the moderator into a field or the description (allowed_mentions is already empty). No package publish.
