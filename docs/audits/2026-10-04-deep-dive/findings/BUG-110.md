# BUG-110: preset-tool.ts handleVoteUpdate: votedIds is not synced from the detail view, so card and detail vote state diverge
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/v4/preset-tool.ts:915`

## Evidence
- Reproduction: Vote on a card, open its detail, un-vote, go back -> card still 'Voted'; clicking it calls removeVote on a vote that no longer exists -> silent failure
- handleVoteUpdate (:915-921) replaces only the preset/voteCount and never touches votedIds (:113). The detail's vote-update event carries no voted flag. After voting in the list and un-voting in the detail, the card still shows Voted, and clicking it calls removeVote, whose failure is silent.
  - Checked: preset-tool.ts:915-921, :848-858; preset-detail.ts:805-819 emit {preset} only
- Origin: git diff 8ecb878f HEAD -- apps/web-app/src/components/v4/ is empty

## Fix
- Add voted:boolean to the vote-update detail and add or remove preset.id in votedIds in handleVoteUpdate. web-app only.
