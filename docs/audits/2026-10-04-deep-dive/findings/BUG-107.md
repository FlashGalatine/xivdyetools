# BUG-107: dye-palette-drawer.ts filterByType: Metallic chip matches English name (14) instead of the gloss set isMetallic (16)
**Severity:** LOW · **Type:** Logic · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/components/v4/dye-palette-drawer.ts:782`

## Evidence
- Reproduction: Tap Metallic: Gunmetal Black and Pearl White are missing, yet 'Exclude metallic' removes them.
- Line 783 filters on name.includes('metallic'), and dyes.json has 14 such names. METALLIC_STAIN_IDS (dye-vocabulary.ts:63-70, decided 2026-07-30) holds 16 IDs, including 92 Gunmetal Black and 93 Pearl White. DyeDatabase.ts:257-260 derives isMetallic from that set, and DyeFilter.ts:38 already uses it.
  - Checked: dye-palette-drawer.ts:782-785; dye-vocabulary.ts:63-70; grep -ci metallic names in dyes.json = 14
- Origin: git show 8ecb878f:.../dye-palette-drawer.ts:783 has the same includes('metallic')

## Fix
- Filter on d.isMetallic, and on d.isPastel for the pastel chip. Web-app deploy only.
