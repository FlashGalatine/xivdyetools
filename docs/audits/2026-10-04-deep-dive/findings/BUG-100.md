# BUG-100: modal-container.ts attachSheetDrag: ignores inner scrollers and touchcancel on mobile sheets
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/modal-container.ts:265`

## Evidence
- Reproduction: Mobile: collection manager with its inner list scrolled down, drag down >90px to scroll the list -> the whole sheet slides and the modal is dismissed
- touchstart engages the drag whenever the modal body's scrollTop is 0, without checking inner scrollers such as the collection list (max-h-96 overflow-y-auto, collection-manager-modal.ts:99). Dragging down to scroll that list up translates the sheet, and a pull past 90px dismisses it. There is no touchcancel handler, so a cancelled gesture leaves transform and transition:none set.
  - Checked: modal-container.ts:260-293 (no touchcancel); collection-manager-modal.ts:99; modal-container.test.ts has no touch tests
- Origin: git grep 8ecb878f: modal-container.ts:267 'if (body.scrollTop > 0) return'; no diff to HEAD

## Fix
- Skip engagement when the touch target has a scrollable ancestor below body with scrollTop>0; reset the transform and transition on touchcancel.
