# BUG-089: dye-selector.ts updateFavoritesPanel hardcodes the 8-column grid and overrides compactMode's 3-column favourites layout at mount
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/components/dye-selector.ts:680`

## Evidence
- Reproduction: Have >=1 favourite, open Comparison (compactMode DyeSelector) on an lg viewport -> favourites strip uses lg:grid-cols-8 in the narrow panel instead of grid-cols-3
- It is worse than claimed. onMount (dye-selector.ts:464-470) calls updateFavoriteDyes right away, and subscribeFavorites fires immediately too (collection-service.ts:1020-1026). So updateFavoritesPanel (:680) swaps in the 8-col grid at mount, and the compact grid-cols-3 (:588-590) is never visible once any favourite exists. compactMode:true + showFavorites:true are used by comparison/accessibility/gradient/harmony/mixer.
  - Checked: dye-selector.ts:587-590 vs :678-683; onMount :460-470; collection-service.ts:1020-1026; comparison-tool.ts:553
- Origin: git diff 8ecb878f HEAD -- dye-selector.ts empty

## Fix
- Extract one favouritesGridClass() helper honouring options.compactMode and use it in both createFavoritesPanel and updateFavoritesPanel.
