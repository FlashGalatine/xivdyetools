**Severity:** LOW · **Type:** Error handling · **Deploy unit:** packages/core · **Covered by test?** no · **Origin:** MAIN

- `packages/core/scripts/build-locales.ts:114`

## Evidence
- Reproduction: Add stainID 126 to dyes.json with no CSV row: pnpm build succeeds, every locale has 125 names, and getDyeName returns null. On an empty cell, the English-fallback JSONs are already on disk when it exits 1.
- The write loop :114-133 runs before the missingCells exit at :138-152. buildDyeNames (:319-333) iterates CSV rows only. No script line or test cross-checks dyes.json ids (only a comment at :94). The only locale test spot-checks 2 ids (LocaleLoader.test.ts:88-89). Dev-tooling, defended at runtime by the English fallback.
