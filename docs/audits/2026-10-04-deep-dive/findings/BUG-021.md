**Severity:** MEDIUM · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/harmony-tool.ts:313`

## Fix
- Add onUpdate(): void { if (this.selectedDye) this.generateHarmonies(); }, as gradient-tool.ts:466 does. Web-app only.
- Add onUpdate(): if both slots are filled, call findMatchingDyesInternal(), showEmptyState(false) and renderResultsGrid(). Web-app only.
- Skip renderLeftPanel in V4 the way mixer-tool.ts:584-591 does, or destroy the old dyeSelector/panels/marketBoard first (accessibility earlier-audit BUG-070 pattern). End renderContent with updateResults() when selectedDyes.length > 0.
- Call updateResults() at the end of renderContent when selectedDyes.length > 0. Do not overwrite selectedDyes from storage on a re-render (or skip the left panel in V4 as mixer does).
