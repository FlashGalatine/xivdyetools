# BUG-045: stats.ts overview: Avg Cmds/User divides a lifetime total by today's users
**Severity:** LOW · **Type:** Logic · **Deploy unit:** apps/discord-worker · **Covered by test?** no · **Origin:** MAIN · **Other units:** N/A

## Location
- `apps/discord-worker/src/handlers/commands/stats.ts:235`

## Evidence
- Reproduction: 200,000 total commands / 150 users today shows 'Avg Cmds/User 1333.3'.
- stats.ts:239-240 divides stats.totalCommands by uniqueUsersToday. totalCommands is the stats:total counter, whose 30-day TTL is renewed on every put (analytics.ts:181-184), so it is effectively a lifetime count. uniqueUsersToday covers today's usertrack keys only (:316-324). The ratio is therefore meaningless. The panel is admin-only.
- Origin: git show 8ecb878f:apps/discord-worker/src/handlers/commands/stats.ts:240 has the same division.

## Fix
- Drop the metric, or divide a per-day command counter by today's unique users. No package publish.
