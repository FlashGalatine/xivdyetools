**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/services/language-service.ts:188`

## Evidence
- Reproduction: Collection named 'Budget $$' -> toast reads 'Budget $'; importedCopyName on such a name produces a mangled copy name
- language-service.ts:188 passes String(value) as a replace() replacement string, so $$, $&, $` and $' are expanded (node check: 'Added to {name}' with 'Budget $$' gives 'Added to Budget $'); add-to-collection-menu.ts:105/:242 pass user collection names.
  - Checked: language-service.ts:188; add-to-collection-menu.ts:105,242; collection-service.ts:889
- Origin: git log 8ecb878f..HEAD -- apps/web-app/src/services/ is empty
