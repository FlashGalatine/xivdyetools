# BUG-033: gradient.ts/mixer.ts apply dyeFilters after a capped nearest-N search, so steps report no match although allowed dyes exist
**Severity:** MEDIUM · **Type:** Logic · **Deploy unit:** packages/bot-logic · **Covered by test?** no · **Origin:** MAIN · **Other units:** apps/discord-worker (passes prefs.dyeFilters to gradient and mixer)

## Location
- `packages/bot-logic/src/commands/gradient.ts:273`

## Evidence
- Reproduction: /preferences filters exclude_vendor=true, then /gradient #FFFFFF #000000 -> step #666666 shows noMatchFound, distance 999
- Temp repro with excludeVendorDyes (85 of 125 excluded): 21/125 dye hexes find nothing in 10 tries, 7 in 20. White->black gradient gives the #666666 step NONE at distance 999; the Snow White+Soot Black mixer sweep drops its 65% stop. Harmony filters the pool first (harmony.ts:210).
  - Checked: gradient.ts:273-284, mixer.ts:74-89 and 113-118; repro output 'null@10 21 null@20 7', gradient '#666666:NONE:999.0', mixer sweep has 4 stops
- Second, independent check (severity MEDIUM): I could not refute it, and MEDIUM is the right severity. Both commands ask core for the nearest dye (packages/core/src/services/dye/DyeSearch.ts:167, which already skips Facewear), then check the user's filter on that one result. gradient.ts:273 stops after 10 rejected tries and mixer.ts:77-89 after 20. The setting is reachable: discord-worker maps `/preferences` option `vendor` to excludeVendorDyes (preferences.ts:114) and passes prefs.dyeFilters unchanged to gradient (gradient.ts:95) and mixer (mixer-v4.ts:84). Nothing filters earlier. Only vendor exclusion hits the cap, because it removes 85 of the 125 dyes. Metallic, craft, and dark+pastel each left 0 of 125 hexes unmatched. So this is a user-visible wrong result on an opt-in edge path, not a common one, and not cosmetic. HIGH is too high; LOW is too low. The existing filter tests only use excludeMetallic or an empty filter object, so none of them reaches the cap.
- Origin: git show 8ecb878f: gradient.ts:273 'attempt < 10', mixer.ts:77 'maxAttempts = 20'; git diff 8ecb878f HEAD -- packages/bot-logic/src touches only locale JSON

## Fix
- Build the pool once with filterDyes(dyeFilters, getAllDyes()) minus Facewear and take a linear nearest by the matching method, as harmony does, in gradient.ts and mixer.ts. Needs a @xivdyetools/bot-logic publish, then a discord-worker deploy.
