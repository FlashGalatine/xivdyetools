# BUG-112: v4-layout-shell.ts static styles have no @media print: browser print is one clipped page including chrome
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/components/v4/v4-layout-shell.ts:138`

## Evidence
- Reproduction: Ctrl+P on any tool: one clipped page that includes the header, FABs and Options column.
- The only @media print in src is v4-layout.css:17, which sets only the host background. Its comment (18-21) says chrome hiding has to live in the shell's static styles, and none exists there. The :host rule (138-149, 100vh, overflow hidden) and the overflow-y:auto content scroller clip the printout to one sheet. Cosmetic: the app has no print feature.
  - Checked: git grep '@media print' apps/web-app/src -> only styles/v4-layout.css:17; v4-layout-shell.ts:138-149, 168-173
- Origin: shell and styles unchanged 8ecb878f..HEAD (git diff --stat empty)

## Fix
- Add @media print to the shell styles: hide the header, FABs, drawer and sidebar, and set :host and the scrollers to height:auto; overflow:visible. Web-app deploy only.
