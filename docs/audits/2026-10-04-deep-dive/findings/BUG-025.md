# BUG-025: swatch-tool findMatchingDyes filters after a top-(maxResults*3) request, so strong dye filters return fewer than maxResults; closestDyeTo ignores filters
**Severity:** MEDIUM · **Type:** Logic · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/web-app/src/components/swatch-tool.ts:2807`

## Evidence
- Reproduction: maxResults 3, excludeVendorDyes+excludeCraftDyes (or coffers+metallic+cosmic): the 9 nearest dyes are mostly excluded -> 0-2 cards although many allowed dyes exist; the verdict sentence (slot, or empty forward list) names an excluded dye
- Same filter-after-limit shape as the fixed /v1/match/within-distance bug. It is reachable with the shipped vendor/craft exclusion filters.
  - Checked: swatch-tool.ts:2807-2820 requests min(maxResults*3,136), then filters and slices; core CharacterColorService.ts:322-374 returns only the top-k; closeststDyeTo (1981-1988) has no isDyeExcluded check; swatch-tool.test.ts:723-733 only asserts not.toThrow()
- Second, independent check (severity MEDIUM): Confirmed, and the finding holds at MEDIUM. findMatchingDyes asks for min(maxResults*3, 136) dyes (swatch-tool.ts:2807-2809). It filters only after that (2817-2819), and core findClosestDyes returns just the top k (CharacterColorService.ts:322-374). The filter can be reached: the sidebar sends global dyeFilters to 'swatch' (config-sidebar.ts:898-907), which goes through setConfig (swatch-tool.ts:497-532). On real palettes, only the Dye Vendor exclusion causes it: 85 of the 125 dyes are vendor dyes. With it on, a large share of cells shows fewer cards than set, and with maxResults=1 about half show none. Craft, metallic and pastel/dark filters show almost no effect. closestDyeTo (1981-1988) has no isDyeExcluded check. So when the forward list is empty, the verdict sentence (2055) and the slot handoff (2316) name a dye the user excluded. The vendor exclusion is off by default, which makes this an edge path, so MEDIUM fits, not HIGH.
- Origin: git diff 8ecb878f HEAD -- apps/web-app/src/components/swatch-tool.ts is empty; findMatchingDyes/closestDyeTo identical at main

## Fix
- When filters are active, request every dye (or pass a filtered pool), then filter and slice to maxResults; apply isDyeExcluded in closestDyeTo too
