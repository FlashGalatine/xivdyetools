# BUG-120: keyboard-service digit tool shortcuts unreachable from the AZERTY number row
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** none

## Location
- `apps/web-app/src/services/keyboard-service.ts:184`

## Evidence
- Reproduction: French AZERTY laptop (no numpad): press the '1' key (key='&') or Shift+1 (shiftKey true) -> no navigation
- keyboard-service.ts:184-186 requires !e.shiftKey and looks up TOOL_KEY_MAP[e.key]. On AZERTY the unshifted top row yields '&','é',... and digits need Shift, so the documented 1-9/0 shortcuts only work from a numpad.
  - Checked: keyboard-service.ts:32-43 TOOL_KEY_MAP keyed by e.key; :184 !e.shiftKey guard
- Origin: git log 8ecb878f..HEAD -- apps/web-app/src/services/keyboard-service.ts is empty

## Fix
- Map e.code Digit0-9/Numpad0-9 (allowing Shift when e.key is the digit), keeping the other-modifier exclusions; web-app only.
