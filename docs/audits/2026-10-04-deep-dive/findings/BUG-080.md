# BUG-080: budget-tool.ts / mixer-tool.ts: theme-dependent inline colours are not refreshed on a theme change
**Severity:** LOW · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** N/A

## Location
- `apps/web-app/src/components/budget-tool.ts:503`

## Evidence
- Reproduction: Budget open with a ledger -> switch dark to light in the theme modal -> the tier ramp, verdict and accent keep their dark-palette hexes on light cards.
- tierRamp (:504), accent (:517), renderVerdict (:1260), the ledger (:1431) and mixer spreadTone (mixer-tool.ts:1150) read ThemeService.isDarkMode() once, at render, into inline hex styles. The only ThemeService.subscribe callers are theme-modal.ts:60 and v4-app-header.ts:82, so neither tool re-renders on a theme switch. The effect is cosmetic until the next re-render.
  - Checked: budget-tool.ts:504,517,1260,1431; mixer-tool.ts:1150; git grep ThemeService.subscribe
- Origin: git show 8ecb878f:budget-tool.ts:504 `ThemeService.isDarkMode() ? TIER_RAMP_DARK : TIER_RAMP_LIGHT`

## Fix
- In onMount, this.subs.add(ThemeService.subscribe(() => { renderVerdict(); renderLedger(); })); do the same for the mixer field.
