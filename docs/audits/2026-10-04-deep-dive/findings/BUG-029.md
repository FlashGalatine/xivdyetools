## Fix
- getPresets reports apiOk; loadPresets uses a seq plus the captured query and drops stale responses; reconcile requires apiOk and an empty fetched query, and skips local- ids. Also count API rows before hybrid's sort+slice: 15 curated + up to 50 API rows are sliced to 50, so stable/name sorts can drop API rows and get under the earlier-audit BUG-020 full-page guard.
- Skip local- ids in reconcileTombstones and hide Save on local- cards (or dedupe the saved snapshot against localPalettePool). web-app only, no package publish.
- Capture a load sequence number and the query at call time; drop superseded results and pass the fetched query to reconcileTombstones. web-app only.
- Have getPresets report whether the API leg succeeded (throw, or return an apiOk flag) and skip reconcileTombstones unless it did; web-app only.
