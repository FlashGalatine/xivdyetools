# BUG-009: gradient.ts generateGradientOG ranks middle-band dyes by hardcoded 'ciede2000' while printing the delta and footer in the requested algo
**Severity:** MEDIUM · **Type:** Logic · **Deploy unit:** apps/og-worker · **Covered by test?** no · **Origin:** MAIN

## Location
- `apps/og-worker/src/services/svg/gradient.ts:88`

## Evidence
- Reproduction: /og/gradient/A/B/5.png?algo=oklab: a temporary repro over 30 start/end pairs found 17 where the card's middle bands differ from the DEOK-nearest dyes it labels with DEOK figures
- Real. The crawler emits ?algo= on gradient image URLs and the page ranks by that method, but the card picks DE2000-nearest dyes and labels them in the other unit. The repro showed 17/30 pairs differ. Edge path (non-default algo only), so MEDIUM.
  - Checked: gradient.ts:88 ranks with 'ciede2000'; :101 prints deltaForAlgorithm(..,algorithm); og-data-generator.ts:315 forwards algo; web gradient-tool.ts:1853 ranks by this.matchingMethod
- Second, independent check (severity MEDIUM): I could not refute it. apps/og-worker/src/services/svg/gradient.ts:88 always picks middle-band dyes with a hardcoded 'ciede2000'. The same card prints each band's delta (:101) and the footer label (algoTag, :117) in the requested algo. The module docblock says each middle band is the nearest dye, so under ?algo=oklab, rgb, cie76 or redmean the card contradicts its own label. This is a wrong result on an edge path (MEDIUM): the default ciede2000 path is unaffected. The sibling cards mixer.ts:86 and swatch.ts:64 rank with rankKeyForAlgorithm, so gradient.ts is the outlier, not a design choice. A separate issue, not filed here: the web app's default interpolation is hsv and share links carry interpolation=, but the card never reads it. I did not use that to lower this grade.
- Origin: git show 8ecb878f:apps/og-worker/src/services/svg/gradient.ts line 88 is the same hardcoded 'ciede2000'

## Fix
- Rank with rankKeyForAlgorithm(stepHex, candidate.hex, algorithm) and normalise algorithm once at the top, so interpolate() also sees 5.0 spellings. Add an algorithm test like harmony's. og-worker only; the card still interpolates by algo, not by the page's colorSpace, which is a separate divergence.
