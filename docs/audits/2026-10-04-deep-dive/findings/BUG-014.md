# BUG-014: budget-tool.ts handleDeepLink: ?maxDelta= changes matchLine after the slider and label were rendered
**Severity:** MEDIUM · **Type:** State · **Deploy unit:** apps/web-app · **Covered by test?** no · **Origin:** MAIN · **Other units:** N/A

## Location
- `apps/web-app/src/components/budget-tool.ts:442`

## Evidence
- Reproduction: Stored line 8; open /budget?dye=X&maxDelta=14 -> ledger filtered at 14, slider and label show 8; the first drag snaps the line back near 8.
- init renders the slider at :984 and the label at :957 from the stored matchLine. onMount then calls handleDeepLink (:297), which sets matchLine at :445 without touching matchLineValueDisplay, the slider value or renderMain. setConfig (:335-340) does update both labels. findAlternatives (:546-614) never re-renders the match-line section, so the ledger filters at the link's value while the slider shows the stored one. Budget share links always carry maxDelta (:1246). Only ciede2000 is affected; other methods disable the slider.
  - Checked: budget-tool.ts:297,442-447,957,984,1246
- Second, independent check (severity MEDIUM): I could not refute this. BaseComponent.init() runs render() (renderMain → renderMatchLineSection) before onMount(). handleDeepLink then sets this.matchLine at budget-tool.ts:445, but the label (:957) and the slider value (:984) were already built from the stored line, and nothing refreshes them. findAlternatives (:546-614) re-renders the ledger, verdict, target and quick picks, never the match-line section. Neither subscription in onMount fires on subscribe, so no immediate re-render fixes it either. The defect only shows under ciede2000 (the other methods pin the threshold and disable the slider), and only on a shared link whose value differs from the recipient's stored line (default 8). That is an edge path. The ledger itself filters correctly at the link's value. What is wrong is the displayed match line, and the first slider move jumps from the stale position. That fits 'wrong result on an edge path', so MEDIUM stands, though it is close to LOW.
- Origin: git show 8ecb878f:budget-tool.ts has `this.matchLine = this.clampMatchLine(n)` at :445; no commits to the file in 8ecb878f..HEAD

## Fix
- After applying maxDelta, update matchLineValueDisplay and mobileMatchLineValueDisplay and set the slider value, or apply the param before renderMain.
