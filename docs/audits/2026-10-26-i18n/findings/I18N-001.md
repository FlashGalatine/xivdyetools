# I18N-001: Twelve plain-language slash-command choices remain English despite translated descriptions

## Evidence
- choiceLocalizations has no branches for swatch/order, swatch/slot or preset/sort. After initializing every locale and running localizeCommands, the two row-order choices, seven body-slot choices and three preset sort choices have no name_localizations. The swatch option descriptions do carry Japanese. Existing card.swatchSlotName.* supplies all seven body labels in all six locales. Current tests exhaustively gate descriptions, but only selected choice lists.
- Reproduce: Run the read-only ESM probe in review-content.md. In a Japanese Discord client inspect /swatch slot or order and /preset list sort: the choices are Skin, Hair, Slots — file order (default), Most Popular, etc. The probe confirms the registered payload shape; no command registration was performed.
- Test gap: Description gates and selected choice tests omit these three choice families. See [review and verification evidence](../evidence/).

- Primary owner is Discord command metadata; new order/sort locale keys are authored and published in bot-logic before the consumer deploy. Preserve canonical option values.
## Fix
- Reuse card.swatchSlotName.* for slot display names while preserving emoji and canonical values. Author six-language row-order and sort display keys, then cover these three choice families in localize.test.ts. Deliberately English method tags, endonyms and preset categories are outside this finding.
