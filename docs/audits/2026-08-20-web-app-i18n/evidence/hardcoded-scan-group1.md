- dye-search-box.ts:210 builds a selector from the translated aria-label (`'button[aria-label="' + t(...) + '"]'`) — functional, not a display string (fragile if a translation contains `"`, but not an i18n finding).

## Summary

27 findings across 6 of the 7 files. **High: 8** — swatch-tool "Custom (#HEX)" source label, "Row N, Column M", "Closest Swatches" heading, and the "Explore Dye" primary-button label; chara-import's verbatim core parse-error toast and per-slot error text, and the raw `SubRace` enum ("SeekerOfTheSun") rendered in the file-card meta line instead of `getClan()`; plus dye-card-renderer's "N/A" (dead file). **Medium: 7** — chara-import "Same model: " + `', '`-joined list tooltip; dye-selector search and alphabetical sort operating on the English `dye.name` (users in other languages cannot find or sort by the names they see); dye-grid's English-only `aria-label: dye.name`; and three dye-card-renderer aria/title strings (dead file). **Low: 12** — the R·C address grammar and "RGB DIST"/"DISTINGUISH %" method tags (treated as identifiers by design, flagged for a decision), "ID {n}", `{palette} {addr}` / `{name} ({count})` / `{label}: {value}` concatenations, two dead English `||` fallbacks in dye-grid, the producer-string trim, and the raw-slot-key default.
