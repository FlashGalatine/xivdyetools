# BUG-013: Non-default match metrics lose units and precision in exports and swatch summaries
**Severity:** LOW · **Type:** Logic · **Deploy unit:** apps/web-app · **Covered by test?:** No regression assertion; see evidence.

## Location
- `apps/web-app/src/shared/palette-export.ts:158`
- `apps/web-app/src/shared/palette-export.ts:277`
- `apps/web-app/src/components/extractor-tool.ts:2379`

## Evidence
- ExportEntry carries only a delta number and no matchingMethod; describeEntry always renders DeltaE plus toFixed(1), and JSON writes deltaE rounded to two decimals. Extractor, gradient and mixer forward distances from the currently selected metric unchanged. For OKLAB, e.g. 0.024 becomes DeltaE 0.0 in CSS/SCSS/Tailwind, and 0.004 becomes numeric 0 in JSON. The matching metric is not supplied in the export metadata, so exported measures also cannot be interpreted reliably. Swatch selection sentences independently round the same method-dispatched distance to one decimal (:1938/:1943), while reverse badges use two (:1045); generic Delta alone is not asserted to be a false DeltaE label.
- Reproduce: Select OKLAB and a source color with nonzero nearest-dye distance below 0.05; export from Extractor, Mixer or Gradient. Commented output reports DeltaE 0.0, while the core metric vocabulary specifies three OKLAB decimals. A swatch with such a match also says the dye sits 0.0 away. Use a distance below 0.005 to expose JSON rounding to zero. Static trace only; no runtime repro executed.
- Test gap: shared/__tests__/palette-export.test.ts:38 uses only delta 3.42; :53 pins DeltaE 3.4 and :96 pins deltaE 3.42. No method field or small OKLAB value is exercised. Components reviewer supplied swatch precision sinks; reviewed tests do not establish method-aware summaries. See [review and verification evidence](../evidence/).

- Current v4-result-card has a dedicated DeltaE2000 readout; this finding does not claim that readout is a native OKLAB distance. Core BAND_METHOD_DP and Gradient/Mixer metric views establish the native precision rule.
## Fix
- Carry matchingMethod through export payloads, preserve its identity in JSON and format with the core metric vocabulary/precision (BAND_METHOD_DP gives OKLAB three places). Use the same precision in swatch summaries and reverse badges. Keep generic Delta labels where intended but identify the selected metric nearby.
