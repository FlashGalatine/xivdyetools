# BUG-009: Favorite list can exceed Discord's embed description limit for legal preset names
**Severity:** LOW · **Type:** Edge case · **Deploy unit:** apps/discord-worker · **Covered by test?:** No regression assertion; see evidence.

## Location
- `apps/discord-worker/src/handlers/commands/preset.ts:1324`
- `apps/discord-worker/src/handlers/commands/preset.ts:1334`
- `apps/discord-worker/src/services/preset-favorites.ts:34`

## Evidence
- All 50 favorites are joined into one description with no total budget. Legal 50-character names can expand to 100 characters after markdown escaping; sanitizePresetName permits 100. HTTP rejection returns false and this adapter ignores it.
- Reproduce: Favorite 50 distinct legal presets whose 50-character names contain underscores. Sanitized names alone can exceed 4096 characters before numbering/categories; edit fails.
- Test gap: preset.test.ts has no favorite-list cases. Add a 50-entry escaped-name case asserting <=4096 description and handling failed edit. See [review and verification evidence](../evidence/).

## Fix
- Paginate or budget complete lines within 4096 including escaped names and truncation notice; check edit success.
