# BUG-020: Palette-driven Gradient and Comparison selections do not request their prices
**Severity:** LOW · **Type:** Logic · **Deploy unit:** apps/web-app · **Covered by test?:** No regression assertion; see evidence.

## Location
- `apps/web-app/src/components/gradient-tool.ts:1322`
- `apps/web-app/src/components/gradient-tool.ts:1784`
- `apps/web-app/src/components/gradient-tool.ts:637`

## Evidence
- Gradient updates interpolation for endpoint picks, pins and algorithm changes without fetching prices; its only calls to fetchPricesForDisplayedDyes are in market-config handlers at :637/:649. Comparison.addDye, used by selectDye from the live v4 drawer, updates cards/results/storage but never fetchAndUpdatePrices. Its old embedded-selector listeners do fetch, but the v4 palette route does not use them. With prices enabled before selection and cold cache, the displayed price rows stay empty until a market/display change triggers a fetch.
- Reproduce: Enable market prices, then select new Gradient endpoints or select Comparison dyes from the app-wide drawer while cache is cold. Observe no new price request and blank rows. Changing server/toggling prices causes them to load. Gradient restored selections have the same omission.
- Test gap: gradient-tool.test.ts:1266-1275 proves server changes refetch after a ramp is mounted, not the ramp-selection trigger. comparison tests selectDye for selection logic and price tests exercise legacy MarketBoard relays, not a cold-cache v4 selection. See [review and verification evidence](../evidence/).

- Exclude restored/shared Comparison selections, which explicitly fetch. The finding covers live v4 Comparison picks and Gradient recomputation/restored endpoints. DyeSelector.setSelectedDyes emits no selection event, so it supplies no indirect fetch.
## Fix
- Have the canonical results/selection-change path fetch the newly displayed dyes when price display is enabled, respecting existing service request coalescing and price toggles; cover direct v4 selectDye plus restored Gradient endpoints.
