# BUG-004: logger's cycle guard returns the raw node, so a secret reachable through a cycle is emitted unredacted
**Severity:** MEDIUM · **Type:** Logic / redaction bypass · **Deploy unit:** `@xivdyetools/logger` (published npm API; consumed by every worker and web-app) · **Covered by test?** no — the test that builds this exact case asserts only `not.toThrow()`

## Location
- `packages/logger/src/core/base-logger.ts:301-307` — `if (g.ancestors.has(context)) return context;` returns the **raw, unprocessed** object, as its own comment states ("genuine cycle → return the raw, unprocessed reference"). `redactArrayItems` does the same at `:408-410`.
- `packages/logger/src/core/base-logger.test.ts:753-758` — "does not recurse forever on a cycle reached through an array" builds `inner = { token: 'shhh' }` behind a cycle and asserts only that the call does not throw.

## Evidence
- Runnable repro: `evidence/scripts/repro-logger-cycle.mjs`, output in `evidence/repro-logger-cycle.txt`. Logging `ctx = { token: 'shhh-super-secret', inner: { back: ctx } }` through the built package emits:
  ```json
  {"context":{"token":"[REDACTED]","inner":{"back":{"token":"[REDACTED]","inner":{"back":{"token":"shhh-super-secret","inner":"[Circular]"}}}}}}
  ```
  The secret is reachable at `context.inner.back.inner.back.token`. `safeStringify` inserts `[Circular]` one level *past* the secret, so the cutoff arrives too late to help.
- The top-level `token` is correctly `[REDACTED]`, which is why the existing suite looks healthy: every assertion checks the shallow copy, none checks the graph.
- No current in-repo call site passes a cyclic context, so the exposure today is to consumers of the published package and to any future call site that logs a rich object with a back-reference.

## Fix
- On a cycle, emit a sentinel (`'[Circular]'`) instead of the live reference, in both `redactSensitiveFields` and `redactArrayItems` — the value is unusable in output anyway, and returning it is the only reason the secret survives.
- Rewrite `base-logger.test.ts:753-758` to assert the emitted string does **not** contain `'shhh'`; `not.toThrow()` alone cannot fail on this defect. Add the object-cycle twin of the array case.
- Needs a `@xivdyetools/logger` publish before consumers pick it up — two sprints.
