# BUG-007: the extractor prints raw RGB distance as ΔE, so every match card is mis-graded
**Severity:** HIGH · **Type:** Logic / wrong user-facing number · **Deploy unit:** `web-app` · **Covered by test?** no

## Location
- `apps/web-app/src/components/extractor-tool.ts:2089,2094` — `distance: ColorService.getColorDistance(hex, dye.hex)` for both the closest dye and the within-distance list.
- `apps/web-app/src/components/extractor-tool.ts:2155` — that value is placed in `deltaE: dye.distance` next to `matchingMethod: this.matchingMethod`.
- `packages/core/src/services/color/ColorConverter.ts:471-484` — `getColorDistance` is documented and implemented as plain RGB Euclidean: "Returns 0 for identical colors, ~441.67 for white vs black".
- `apps/web-app/src/components/v4/result-card.ts:998` — `getDeltaE2000()` returns `deltaE` **verbatim** when `matchingMethod` is `undefined` or `'ciede2000'`, which is the default.

## Evidence
- The two scales are unrelated: ΔE2000 runs roughly 0–100 with the card's quality bands cut at 5 / 10 / 20, while this number runs 0–441.67. A genuinely excellent match sits well above the "good" band once measured in RGB units, so the card grades good matches as poor and prints a number that means nothing to the user.
- The card is not defending itself here — its guard is written to trust a `ciede2000`-labelled value, and the extractor supplies exactly that label with a non-ΔE number.
- The same class reaches the auto-extract path through core: `PaletteService.extractAndMatchPalette` reports `rgbDistance` regardless of the requested method ([[BUG-008]]).
- Not caught because no test compares the emitted `deltaE` against an independently computed ΔE2000 for the same pair.
- The sibling tool shows the correct shape: `gradient-tool` calls `getDistanceForMethod(..., this.matchingMethod)` on every displayed drift, and `comparison-tool` passes a real ΔE2000.

## Fix
- Compute the displayed distance with `getDistanceForMethod(hex, dye.hex, this.matchingMethod)` so the number matches the label, in both the closest-dye and within-distance branches.
- Add a test asserting the emitted `deltaE` equals an independently computed ΔE2000 for a known pair — the assertion the current suite lacks.
